<h2 id="vscode-설정하기">VSCode 설정하기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#vscode-설정하기"><span class="anchor-icon">#</span></a></h2>
<p>이번 포스트는 VSCode를 사용하여 모노레포 프로젝트를 생성합니다. 다른 IDE를 사용하고 계신다면 이 부분은 넘기서도 무방합니다. VSCode를 사용한다면 아래 목록의 순서대로 진행합니다.</p>
<ol>
<li><strong><a href="https://marketplace.visualstudio.com/items?itemName=arcanis.vscode-zipfs">ZipFS</a> VSCode 확장 프로그램 설치하기</strong>: <code>Yarn Berry</code>는 Zip 형태로 의존성을 관리하기 때문에 Zip 파일을 읽기 위한 확장 프로그램이 필요합니다.</li>
<li><strong>TypeScript 설치하기</strong>: TypeScript를 사용하기 위해 모노레포 프로젝트 루트에 <code>yarn add -D typescript</code> 명령어를 사용하여 TypeScript를 설치 해 줍니다.</li>
<li><strong>yarn sdk 설치</strong>: VSCode에서 <code>Yarn Berry</code>를 사용하기 위해서는 yarn의 vscode sdk가 필요한데, <code>yarn dlx @yarnpkg/sdks vscode</code> 명령어를 사용하여 설치합니다.</li>
<li><strong>TypeScript 허용</strong>
yarn sdk 설치가 끝나면, 아래 그림과 같은 팝업이 뜨는데, <code>Allow</code>를 클릭하여 TypeScript 사용을 허용해 줍니다.
<img src="/assets/img/posts/etc/typescript_allow_1.png" alt="TypeScript 허용" loading="lazy" decoding="async" width="459" height="138" srcset="/assets/img/posts/etc/nextImageExportOptimizer/typescript_allow_1-opt-640.WEBP 640w" sizes="(max-width: 640px) 100vw, 1000px">
만약 위의 팝업이 뜨지 않거나 <code>Dismiss</code> 클릭하는 등으로 TypeScript 사용 허용을 해주지 못했다면, 아래 그림과 같이 <code>Command Pallette</code>(Cmd(Crtl) + Shift + P) -> <code>TypeScript: Select TypeScript Version...</code> -> <code>Use Workspace Version</code>를 클릭해 줍니다.

<p>모노레포의 워크스페이스의 스크립트를 실행하기 위해 매번 <code>yarn workspace @monorepo/design-system</code>을 타이핑하는 것은 너무 장황할 수 있습니다. 이런 타이핑 양을 줄이기 위해 아래 코드와 같이 <code>package.json</code>의 <code>scripts</code> 필드를 작성하면 작성해야 할 커맨드 라인이 줄일 수 있습니다.</p>

<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  "ds"</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">"yarn workspace @monorepo/design-system"</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">,</span></span>
<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  "service"</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">"yarn workspace @monorepo/service"</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<p>위의 코드와 같이 작성하면 <code>yarn ds add react</code>의 명령어가 <code>yarn workspace @monorepo/design-system add react</code>와 동일하게 동작하게 됩니다. <code>yarn service add react</code>는 <code>yarn workspace @monorepo/service add react</code>와 동일합니다.</p>
<h3 id="yarn-berry-플러그인"><code>Yarn Berry</code> 플러그인<a class="anchor after" aria-hidden="true" tabindex="-1" href="#yarn-berry-플러그인"><span class="anchor-icon">#</span></a></h3>
<p><code>Yarn Berry</code>는 패키지를 편리하게 관리할 수 있게 도와주는 플러그인들을 제공합니다. <a href="https://yarnpkg.com/features/plugins">Yarn Berry Plugins</a>에서 제공하는 플러그인들을 확인할 수 있습니다.</p>
<p>대표적으로, <code>yarn plugin import workspace-tools</code> 명령어로 <code>workspace-tools</code>를 설치하면 <code>yarn workspaces foreach &#x3C;commandName></code> 명령어를 사용할 수 있게 됩니다. 이 명령어는 아래 그림과 같이 모든 워크스페이스의 스크립트를 실행합니다.</p>
