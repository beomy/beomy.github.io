<h2 id="라이프-사이클-스크립트란">라이프 사이클 스크립트란<a class="anchor after" aria-hidden="true" tabindex="-1" href="#라이프-사이클-스크립트란"><span class="anchor-icon">#</span></a></h2>
<p><code>scripts</code> 필드에는 개발자가 임의로 정의한 스크립트 뿐만 아니라, 정해진 몇가지 스크립트 명령어가 있습니다. 이런 스크립트를 라이프 사이클 스크립트라고 하는데, 패키지의 <code>install</code> 혹은 <code>publish</code> 명령어가 실행되기 전/후에 호출됩니다.</p>
<h3 id="패키지-매니저-차이">패키지 매니저 차이<a class="anchor after" aria-hidden="true" tabindex="-1" href="#패키지-매니저-차이"><span class="anchor-icon">#</span></a></h3>
<p>라이프 사이클 스크립트는 어떤 패키지 매니저(NPM, Yarn)를 사용하느냐에 따라 다르기 때문에 라이프 사이클 스크립트를 사용할 때 사용하는 패키지 매니저가 제공하는 라이프 사이클 스크립트인지 확인이 필요합니다.</p>
<p>예를 들어, <a href="https://typicode.github.io/husky/#/"><code>husky</code></a> 패키지는 설치된 후 <code>husky install</code> 이라는 명령어가 실행되어야 하기 때문에 패키지가 설치 된 후 실행되는 라이프 사이클 스크립트를 사용해야 합니다. NPM을 사용하는 경우 <code>prepare</code>라는 스크립트를 사용할 수 있지만 Yarn 2+은 <code>prepare</code> 스크립트를 지원하지 않기 때문에 <code>postinstall</code>이라는 스크립트를 사용해야 합니다.</p>
<h3 id="pre와-post-스크립트">Pre와 Post 스크립트<a class="anchor after" aria-hidden="true" tabindex="-1" href="#pre와-post-스크립트"><span class="anchor-icon">#</span></a></h3>
<p>NPM의 경우 커스텀 스크립트의 경우에도 사전, 사후 스크립트를 지원합니다. <code>pre&#x3C;event></code>, <code>post&#x3C;event></code>와 같이 스크립트 이름으로 작성하여 사용할 수 있습니다. 아래 코드와 같이 <code>package.json</code>의 <code>scripts</code> 필드를 작성하면,</p>

<p>Yarn 2+의 경우 위의 그림과 같이 커스텀 스크립트의 Pre, Post 스크립트를 지원하지 않습니다.</p>
<h2 id="라이프-사이클-스크립트-종류">라이프 사이클 스크립트 종류<a class="anchor after" aria-hidden="true" tabindex="-1" href="#라이프-사이클-스크립트-종류"><span class="anchor-icon">#</span></a></h2>
<p>NPM은 Pre/Post 스크립트 뿐만 아니라, <code>prepare</code>, <code>prepublish</code>, <code>prepublishOnly</code>, <code>prepack</code>, <code>postpack</code>, <code>dependencies</code> 6개의 라이프 사이클 스크립트가 있습니다. 반면에 Yarn 2+는 Pre/Post 스크립트를 지원하지 않고, <code>prepack</code>, <code>postpack</code>, <code>prepublish</code>, <code>postintall</code> 4개의 라이프 사이클 스트립트만 존재합니다. 라이프 사이클 스크립트를 하나씩 살펴보도록 하겠습니다.</p>
<h3 id="prepare-npm"><code>prepare</code> (NPM)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#prepare-npm"><span class="anchor-icon">#</span></a></h3>
<p><code>prepare</code> 스크립트는 패키지가 패킹 되기 전에 실행되는 스크립트로 <code>npm publish</code>, <code>npm pack</code> 의 스크립트가 실행될 때, 로컬에서 파라이터 없이 <code>npm install</code> 스크립트가 실행될 때 호출됩니다.</p>
<h3 id="prepublish-deprecated"><code>prepublish</code> (DEPRECATED)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#prepublish-deprecated"><span class="anchor-icon">#</span></a></h3>
<p><code>prepublish</code> 스크립트는 지원 중단 되었습니다. <code>npm publish</code> 스크립트가 실행될 때는 호출되지 않고, <code>npm ci</code>, <code>npm install</code> 스크립트가 실행될 때 호출됩니다.</p>
<h3 id="prepublishonly-npm"><code>prepublishOnly</code> (NPM)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#prepublishonly-npm"><span class="anchor-icon">#</span></a></h3>
<p><code>prepublishOnly</code> 스크립트는 패키지가 준비(prepared), 압축(packed) 되기 전에 실행되는 스크립트로 <code>npm publish</code> 스크립트가 실행될 때만 호출됩니다.</p>
<h3 id="prepack-npm-yarn-2"><code>prepack</code> (NPM, Yarn 2+)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#prepack-npm-yarn-2"><span class="anchor-icon">#</span></a></h3>
<p><code>prepack</code> 스크립트는 패키자가 압축되기 전에 호출되는 스크립트입니다. <code>npm pack</code>, <code>npm publish</code> 스크립트가 실행될 때 호출됩니다.</p>
<h3 id="postpack-npm-yarn-2"><code>postpack</code> (NPM, Yarn 2+)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#postpack-npm-yarn-2"><span class="anchor-icon">#</span></a></h3>
<p><code>postpack</code> 스크립트는 압축 파일이 생성되고, 최종 목적지(예를 들어 NPM 배포)에 이동하기 전에 호출됩니다.</p>
<h3 id="dependencies-npm"><code>dependencies</code> (NPM)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#dependencies-npm"><span class="anchor-icon">#</span></a></h3>
<p><code>dependencies</code> 스크립트는 <code>node_modules</code> 디렉토리가 수정되었을 때 호출됩니다.</p>
