1a:T863b,<p>처음 자바스크립트는 모듈을 가져오거나 내보내는 방법이 없어, 하나의 파일에 모든 기능들이 들어가야 했습니다. CJS, AMD, UMD, ESM이 등장 후에는 모듈로 개발하고 배포할 수 있게 되었습니다. 이번 포스트에서는 모듈화 개발을 할 수 있게 한 CJS, AMD, UMD, ESM가 무엇인지 살펴보겠습니다.</p>
<h2 id="cjs-commonjs">CJS (CommonJS)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#cjs-commonjs"><span class="anchor-icon">#</span></a></h2>
<p>CommonJS(<a href="http://www.commonjs.org/">http://www.commonjs.org/</a>)는 이름의 'Common'에서 알 수 있듯이 JavaScript를 브라우저에서뿐만 아니라 범용 언어로 사용할 수 있도록 하겠다는 의지를 가진 워킹 그룹입니다.</p>

<p>CommonJS는 아래 코드와 같이 동기로 동작하는 특징을 가집니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">var</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> foo </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> require</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#032563;--shiki-dark:#ADDCFF">'foo'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">);</span></span>

<h2 id="amd-asynchronous-module-definition">AMD (Asynchronous Module Definition)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#amd-asynchronous-module-definition"><span class="anchor-icon">#</span></a></h2>
<p>CommonJS는 모든 파일이 로컬 디스크에 있어 필요할 때 바로 불러올 수 있는 상황을 전제로 합니다. 즉 동기적인 동작이 가능한 서버사이드 자바스크립트 환경을 전제로 합니다. 브라우저에서 이런 방식은 필요한 모듈이 모두 다운로드할 때까지 아무것도 할 수 없는 상태가 되어 치명적인 단점이 됩니다.</p>
<p>AMD 그룹은 비동기 상황에서 자바스크립트 모듈을 사용하기 위해 CommonJS에서 함께 논의하다 합의점을 이루지 못하고 독립한 그룹입니다. CommonJS가 자바스크립트를 브라우저 밖으로 꺼내기 위해 탄생된 그룹이고, AMD는 브라우저에 중점을 둔 그룹입니다.</p>
<h3 id="코드-예제-1">코드 예제<a class="anchor after" aria-hidden="true" tabindex="-1" href="#코드-예제-1"><span class="anchor-icon">#</span></a></h3>
<p>아래 코드는 AMD에서 모듈로 추출하는 코드입니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// 종속성을 갖는 모듈인 'package/lib'를 모듈 선언부의 첫 번째 파라미터에 넣으면,</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// 'package/lib'은 콜백 함수의 lib 파라미터 안에 담깁니다.</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">define</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">([</span><span style="color:#032563;--shiki-dark:#ADDCFF">'package/lib'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">], </span><span style="color:#A0111F;--shiki-dark:#FF9492">function</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">lib</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // 로드된 종속 모듈을 아래와 같이 사용할 수 있습니다.</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  function</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> foo</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> () {</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    lib.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">log</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#032563;--shiki-dark:#ADDCFF">'hello world!'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">);</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // 생성된 foo 함수는 리턴을 통해 foobar라는 이름의 다른 모듈로 추출될 수 있습니다.</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  return</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    foobar: foo</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  };</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">});</span></span></code></pre>
<p>선언된 모듈들을 아래와 같이 <code>require</code>로 사용할 수 있습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">require</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">([</span><span style="color:#032563;--shiki-dark:#ADDCFF">'package/myModule'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">], </span><span style="color:#A0111F;--shiki-dark:#FF9492">function</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">myModule</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  myModule.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">foobar</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">();</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">});</span></span></code></pre>
<h3 id="특징-비동기">특징: 비동기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#특징-비동기"><span class="anchor-icon">#</span></a></h3>

<h2 id="umd-universal-module-definition">UMD (Universal Module Definition)<a class="anchor after" aria-hidden="true" tabindex="-1" href="#umd-universal-module-definition"><span class="anchor-icon">#</span></a></h2>
<p>AMD와 CommonJS 두 그룹으로 나누어지다 보니 서로 호환되지 않는 문제가 발생하게 됩니다. 이것을 해결하기 위해 나온 것이 UMD입니다. UMD는 디자인 패턴에 더 가깝습니다. AMD와 CommonJS, window에 추가하는 방식까지 모두 가능한 모듈을 작성하는 방식입니다.</p>
<h3 id="코드-예제-2">코드 예제<a class="anchor after" aria-hidden="true" tabindex="-1" href="#코드-예제-2"><span class="anchor-icon">#</span></a></h3>
<p>AMD는 <code>define</code>을 사용하고, CommonJS는 <code>module.exports</code>를 사용합니다. 이 차이를 이용하여 UMD를 만들 수 있습니다. UMD는 두 부분으로 구성됩니다.</p>
<ul>
<li>모듈 로더를 확인하는 즉시 실행 함수(IIFE): 이 함수는 <code>root</code>(전역 범위)와 <code>factory</code>(모듈을 선언하는 함수) 2개의 파라미터를 가집니다.</li>
<li>모듈을 생성하는 익명 함수: 이 함수가 즉시 실행 함수의 2번째 파라미터로 전달됩니다.</li>
</ul>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#A0111F;--shiki-dark:#FF9492">function</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">root</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#702C00;--shiki-dark:#FFB757">factory</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  if</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#A0111F;--shiki-dark:#FF9492">typeof</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> define </span><span style="color:#A0111F;--shiki-dark:#FF9492">===</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'function'</span><span style="color:#A0111F;--shiki-dark:#FF9492"> &#x26;&#x26;</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> define.amd) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    // AMD</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    define</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">([</span><span style="color:#032563;--shiki-dark:#ADDCFF">'exports'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'b'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">], factory);</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  } </span><span style="color:#A0111F;--shiki-dark:#FF9492">else</span><span style="color:#A0111F;--shiki-dark:#FF9492"> if</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#A0111F;--shiki-dark:#FF9492">typeof</span><span style="color:#023B95;--shiki-dark:#91CBFF"> exports</span><span style="color:#A0111F;--shiki-dark:#FF9492"> ===</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'object'</span><span style="color:#A0111F;--shiki-dark:#FF9492"> &#x26;&#x26;</span><span style="color:#A0111F;--shiki-dark:#FF9492"> typeof</span><span style="color:#023B95;--shiki-dark:#91CBFF"> exports</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">.nodeName </span><span style="color:#A0111F;--shiki-dark:#FF9492">!==</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'string'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    // CommonJS</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    factory</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#023B95;--shiki-dark:#91CBFF">exports</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#622CBC;--shiki-dark:#DBB7FF">require</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#032563;--shiki-dark:#ADDCFF">'b'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">));</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  } </span><span style="color:#A0111F;--shiki-dark:#FF9492">else</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    // Browser globals</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    factory</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">((root.commonJsStrict </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {}), root.b);</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}(</span><span style="color:#023B95;--shiki-dark:#91CBFF">this</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#A0111F;--shiki-dark:#FF9492">function</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">exports</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#702C00;--shiki-dark:#FFB757">b</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  //use b in some fashion.</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // attach properties to the exports object to define</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // the exported module properties.</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">  exports</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">action</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#A0111F;--shiki-dark:#FF9492"> function</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> () {};</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}));</span></span></code></pre>
<p>위의 코드를 보면, <code>exports</code>와 <code>module</code>이 존재하면 CommonJS 방식으로, <code>define</code>이 함수이고 <code>define.amd</code>가 존재할 경우 AMD 방식으로 그것도 아니라면 window 객체에 모듈을 내보냅니다.</p>
<h3 id="특징-여러-모듈-로더에서-사용-가능">특징: 여러 모듈 로더에서 사용 가능<a class="anchor after" aria-hidden="true" tabindex="-1" href="#특징-여러-모듈-로더에서-사용-가능"><span class="anchor-icon">#</span></a></h3>
<p>UMD의 특징은 위에서 말했던 것처럼 AMD와 CommonJS 모두 사용 가능하다는 점입니다. AMD는 클라이언트 사이드에서 많이 사용되고, CommonJS는 서버 사이드에서 많이 사용되기 때문에, UMD를 사용하면 두 개의 모듈을 따로 만들 필요가 없게 됩니다.</p>

<p>ES6에 자바스크립트 모듈 기능이 추가되었습니다.</p>

<p>ESM은 ECMAScript에서 지원하는 자바스크립트 공식 모듈 시스템입니다. 아직 브라우저에서 <code>import</code>와 <code>export</code>를 지원하지 않아 번들러를 함께 사용해야 합니다.</p>

<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// 변수 x는 foo.mjs에서 선언한 변수 x와 스코프가 다른 변수이다.</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">var</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> x </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'bar'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">console.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">log</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(x); </span><span style="color:#66707B;--shiki-dark:#BDC4CC">// bar</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// 변수 x는 전역 변수가 아니며 window 객체의 프로퍼티도 아니다.</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">console.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">log</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(window.x); </span><span style="color:#66707B;--shiki-dark:#BDC4CC">// undefined</span></span></code></pre>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// module.mjs</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> test</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'hello world!'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// export 사용이 가능합니다.</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">export</span><span style="color:#A0111F;--shiki-dark:#FF9492"> default</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> test;</span></span></code></pre>
<p><code>type="module"</code>을 사용하면 해당 파일에 <code>import</code>와 <code>export</code> 사용이 가능합니다. 또한 파일마다 독립적인 스코프를 가져, <code>foo.mjs</code> 파일과 <code>bar.mjs</code>파일의 <code>window</code>는 서로 공유되지 않습니다.</p>
<p><code>type="module"</code>는 아직 많은 브라우저에서 모듈 시스템을 지원하지 않기 때문에 webpack이나 rollup 등의 번들러를 사용하는 것이 좋습니다.</p>
<h2 id="요약">요약<a class="anchor after" aria-hidden="true" tabindex="-1" href="#요약"><span class="anchor-icon">#</span></a></h2>
<ul>
<li>CJS(CommonJS): 동기적인 특징으로 서버 사이드에서 사용하기 용이합니다.</li>
<li>AMD(Asynchronous Module Definition): 비동기적인 특징으로 클라이언트 사이드에서 사용하기 용기합니다.</li>
<li>UMD(Universal Module Definition): CJS와 AMD 모두 사용 가능한 모듈을 만들기 위해 사용됩니다.</li>
<li>ESM(ECMAScript Module): 자바스크립트 공식 모듈 시스템입니다.
<ul>
<li><code>&#x3C;script type="module" src="index.mjs"></code>을 사용하여 브라우저에서도 모듈 시스템을 사용할 수 있습니다.</li>
</ul>
</li>
</ul>
