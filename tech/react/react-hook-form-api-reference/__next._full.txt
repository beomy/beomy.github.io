<li>기본 값을 <code>undefined</code>로 정의하는 것은 피해야 합니다.</li>
<li><code>reset</code> 함수로 초기화할 경우, <code>defaultValues</code>에 설정한 값으로 초기화됩니다.</li>

</ul>
</li>

</li>

<ul>
<li><code>true</code>가 기본 값으로 <code>ture</code>로 설정한 경우, 유효성 검사에 실패한 첫 번째 요소가 포커스 됩니다.</li>
<li>이 옵션을 사용하기 위해서는 <code>register</code> 함수의 반환 값인 <code>ref</code>(<code>Controller</code> 컴포넌트의 경우 <code>render</code> 함수의 <code>field.ref</code> 파라미터)가 요소의 <code>ref</code>에 전달되어야 합니다.</li>

<li><code>criteriaMode: 'firstError' | 'all'</code>
<ul>
<li><code>firstError</code>가 기본 값으로 한 요소에 여러 유효성 에러가 발생한 경우 첫 번째 유효성 에러만 <code>formState.errors</code> 객체에 담깁니다.</li>
<li><code>all</code>로 설정한 경우 모든 유효성 에러가 <code>formState.errors.types</code> 객체에 담깁니다.</li>
</ul>
</li>
<li><code>delayError: number</code>
<ul>
<li>입력된 ms초만큼 사용자에게 에러 표시를 지연시킵니다.</li>
<li>유효성 검사가 통과될 경우에는 즉각 적용됩니다.</li>

<ul>
<li><code>name: string</code>: 값을 업데이트할 요소의 이름을 지정합니다.</li>
<li><code>value: unknown</code>: 요소의 업데이트할 값을 지정합니다.</li>
<li><code>config?: { shouldValidate: boolean; shouldDirty: boolean; shouldTouch: boolean; }</code>
<ul>
<li><code>setValue</code> 함수를 실행 후에, 폼 상태를 업데이트하기 위한 플래그 설정을 지정합니다.</li>

<ul>

</ul>
</li>
<li><code>config.shouldDirty</code>를 <code>true</code>로 설정하면, <code>setValue</code> 함수로 값이 업데이트된 후 <code>defaultValues</code>에서 설정 한 값과 비교하여 변경되었다면 <code>formState.isDirty</code> 플래그는 <code>true</code>가 됩니다.</li>

</ul>

<h2 id="controller"><code>Controller</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#controller"><span class="anchor-icon">#</span></a></h2>
<p>React Hook Form은 기본적으로 Uncontrolled 방식을 사용하지만 <code>Controller</code> 컴포넌트를 사용하는 Controlled 방식을 사용하여 <a href="https://ant.design/">Ant Design</a>이나 <a href="https://mui.com/">Mui</a> 등의 UI 라이브러리와 함께 사용할 수 있습니다.</p>
<h4 id="props-12">props<a class="anchor after" aria-hidden="true" tabindex="-1" href="#props-12"><span class="anchor-icon">#</span></a></h4>
<p><code>Controller</code> 컴포넌트의 속성은 아래와 같습니다.</p>
<ul>
<li><code>name: FieldValues</code>: <code>register</code> 함수의 첫 번째 파라미터와 동일한 역할을 합니다. 요소를 구별할 수 있는 유니크한 값을 지정해야 합니다.</li>
<li><code>control: Control</code>: <code>useForm</code> 함수의 반환 값인 <code>control</code>을 그대로 전달해야 합니다. <code>FormProvider</code>를 사용했을 경우 생략 가능합니다.</li>
<li><code>render: Function</code>: 화면에 그려질 컴포넌트를 반환하는 함수입니다.</li>
<li><code>defaultValue: unknown</code>: 요소의 기본값을 정의합니다. 해당 필드에 값이 정의되거나, <code>useForm</code>의 <code>defaultValues</code>에 값이 정의되어야 합니다. <code>undefined</code>는 사용할 수 없기 때문에 <code>null</code> 혹은 <code>''</code>를 사용하여 정의되지 않을 값을 대신해야 합니다.</li>
<li><code>rules: RegisterOptions</code>: <code>register</code> 함수의 <code>RegisterOptions</code> 옵션과 동일한 값을 설정할 수 있습니다.</li>

<h4 id="render-함수의-props"><code>render</code> 함수의 props<a class="anchor after" aria-hidden="true" tabindex="-1" href="#render-함수의-props"><span class="anchor-icon">#</span></a></h4>

<ul>
<li><code>field</code>: 요소의 속성으로 전달되어야 하는 값들을 담고 있는 객체입니다.

<li><code>field.onBlur: () => void</code>: 요소의 blur 이벤트가 발생할 경우 호출되어야 하는 함수입니다.</li>

</ul>
</li>
<li><code>formState</code>: <code>useForm</code>의 <code>formState</code> 반환 값과 동일한 값을 가집니다. <a href="/tech/react/react-hook-form-api-reference/#formstate">formState</a>를 참고 바랍니다.</li>
