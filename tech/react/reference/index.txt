<p><strong>TL;DR</strong></p>
<ul>
<li><code>useRef</code>: 렌더링에 영향을 주지 않고 리렌더링이 되더라도 값이 변경되지 않는 변수를 만들 때 사용하는 훅입니다. 대부분의 경우 <code>useRef</code> 훅의 반환 값을 <code>&#x3C;input ref="..." /></code>의 <code>ref</code> 속성에 전달하여 DOM을 접근하기 위해 사용됩니다.</li>
<li><code>forwardRef</code>: 부모 컴포넌트에서 자식 컴포넌트의 <code>ref</code> 속성을 통해 자식 컴포넌트의 DOM을 접근하기 위해 사용되는 함수입니다.</li>
<li><code>useImperativeHandle</code>: 부모 컴포넌트에서 자식 컴포넌트의 <code>ref</code> 속성을 통해 노출되는 값을 커스텀하기 위해 사용되는 훅입니다.</li>
</ul>
</blockquote>
<p>React에서 DOM에 접근하기 위해 사용되는 것이 <code>ref</code>입니다. <code>ref</code>는 <code>&#x3C;div ref={divRef}>...&#x3C;/div></code>와 같이 속성처럼 사용되지만 속성과는 다른 의미를 가지고 있습니다. 이번 포스트에서는 <code>ref</code> 속성을 사용할 때 함께 사용되는 <code>useRef</code>와 <code>forwardRef</code>, <code>useImperativeHandle</code>를 살펴보도록 하겠습니다.</p>
<h2 id="useref"><code>useRef</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#useref"><span class="anchor-icon">#</span></a></h2>
<p><code>useRef</code>는 렌더링에 필요하지 않은 값을 참조하는 훅입니다. 클래스형 컴포넌트에서는 <code>useRef</code> 대신 <code>createRef</code>을 사용합니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="tsx"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> ref</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> useRef</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(initialValue)</span></span></code></pre>
<h3 id="파라미터">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터"><span class="anchor-icon">#</span></a></h3>
<ul>
<li><code>initialValue: any</code>
<ul>
<li><code>useRef</code> 훅이 반환하는 <code>ref.current</code> 객체에 설정할 초기값으로 첫 렌더링시 사용되며 이후에는 무시됩니다.</li>
<li>모든 타입을 사용할 수 있습니다.</li>
</ul>
</li>
</ul>
<h3 id="반환값">반환값<a class="anchor after" aria-hidden="true" tabindex="-1" href="#반환값"><span class="anchor-icon">#</span></a></h3>
<ul>
<li><code>ref.current: any</code>
<ul>
<li>처음에는 <code>initialValue</code>로 설정되며 이후에 변경 가능합니다.</li>
<li><code>&#x3C;input ref="ref" /></code>와 같이 <code>ref</code>를 JSX 노드의 <code>ref</code> 속성으로 전달하면 <code>ref.current</code>에 JSX 노드의 DOM이 설정됩니다.</li>
<li>리렌더링이 발생하면 <code>useRef</code>의 반환값은 변경되지 않고 동일한 객체를 반환합니다.</li>
<li><code>ref.current</code> 값을 변경하더라도 리렌더링이 발생하지 않습니다.</li>
</ul>
</li>
</ul>
<h3 id="사용법">사용법<a class="anchor after" aria-hidden="true" tabindex="-1" href="#사용법"><span class="anchor-icon">#</span></a></h3>
<p><code>useRef</code>의 사용법을 살펴보도록 하겠습니다.</p>

<h4 id="값-재생성-하지-않기">값 재생성 하지 않기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#값-재생성-하지-않기"><span class="anchor-icon">#</span></a></h4>

<h2 id="useimperativehandle"><code>useImperativeHandle</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#useimperativehandle"><span class="anchor-icon">#</span></a></h2>
<p><code>useImperativeHandle</code> 훅은 <code>ref</code>로 노출할 대상을 커스텀할 때 사용되는 훅입니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="tsx"><code><span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">useImperativeHandle</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(ref, createHandle, dependencies</span><span style="color:#A0111F;--shiki-dark:#FF9492">?</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">)</span></span></code></pre>
<h3 id="파라미터-2">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터-2"><span class="anchor-icon">#</span></a></h3>
<ul>
<li><code>ref</code>
<ul>
<li><code>forwardRef</code> 함수의 두 번째 파라미터인 <code>ref</code>가 전달되어야 합니다.</li>
</ul>
</li>
<li><code>createHandle</code>
<ul>
<li>상위 컴포넌트에게 노출하려는 값을 반환하는 파라미터가 없는 함수입니다.</li>
</ul>
</li>
<li><code>dependencies?</code>
<ul>
<li><code>useEffect</code> 훅의 두 번째 파라미터와 동일한 종속성 배열입니다.</li>
<li>종속성을 가진 값들을 배열의 형태로 전달해야 하며, 종속성 배열의 값 중 하나라도 변경되면 <code>createHandle</code> 함수가 다시 실행되어, 상위 컴포넌트에 노출되는 값이 변경됩니다.</li>
</ul>
</li>
</ul>
<h3 id="반환값-2">반환값<a class="anchor after" aria-hidden="true" tabindex="-1" href="#반환값-2"><span class="anchor-icon">#</span></a></h3>
<p><code>useImperativeHandle</code> 훅은 <code>undefined</code>를 반환합니다.</p>

<p><code>useImperativeHandle</code> 훅의 사용법을 살펴보도록 하겠습니다.</p>
