<p><strong>TL;DR</strong></p>
<ul>
<li>Suspense도 동시성 렌더링으로, 데이터가 준비되지 않은 컴포넌트를 덜 긴급한 렌더링으로 판단하고 그 외의 렌더링 작업을 우선 진행합니다.</li>
<li>Suspense는 아래의 3가지 장점이 있습니다.
<ul>
<li>데이터 로딩 처리할 수 있습니다.</li>
<li>선언형 UI의 간결함을 가질 수 있습니다.</li>
<li>데이터가 없을 경우와 같은 예외 처리에 대한 고민 없이 본연의 역할에만 충실할 수 있습니다.</li>
</ul>
</li>
<li><code>React.lazy</code>, TanStack Query에서 Suspense를 사용할 수 있습니다. 뿐만 아니라 컴포넌트가 <code>throw new Promise()</code>를 하게 되면 Suspense가 동작하기 때문에 이 원리로 다양하게 활용할 수 있습니다.</li>
<li>하나의 컴포넌트에서 여러 개의 Suspense를 발생시키는 코드는 Waterfall로 동작하여 성능을 저하시킵니다.</li>
</ul>
</blockquote>
<p>Suspense는 컴포넌트가 화면에 노출하기 위해 필요한 데이터가 아직 준비되지 않았다고 알려주는 기능으로 React 16.6 버전에서 실험적 기능으로 등장해 18 버전에서 정식 지원을 시작한 기능입니다.</p>
<h2 id="suspnse-동작-원리">Suspnse 동작 원리<a class="anchor after" aria-hidden="true" tabindex="-1" href="#suspnse-동작-원리"><span class="anchor-icon">#</span></a></h2>
<p>Suspense도 <a href="/tech/react/concurrent-rendering/">[React] Concurrent Rendering - 동시성 렌더링</a>에서 이야기한 동시성 렌더링과 결을 같이합니다. 동시성 렌더링은 긴급한 렌더링과 덜 긴급한 렌더링으로 나누어 긴급한 렌더링을 우선 렌더링 하고 긴급한 렌더링이 없을 경우 덜 긴급한 렌더링을 진행합니다. Suspense도 동일하게 데이터가 준비되지 않은 컴포넌트의 렌더링을 덜 긴급한 렌더링으로 판단하고 그 외의 렌더링 작업을 우선 진행합니다.</p>
<p>아래 코드와 같이 Suspense를 사용하는데, <code>SomeComponent</code> 컴포넌트에서 <code>Promise</code>를 <code>throw</code>하게 되면 <code>Suspense</code> 컴포넌트의 <code>fallback</code> prop에 정의한 <code>Loading</code> 컴포넌트가 화면에 출력되게 됩니다.</p>

<h2 id="suspense를-사용하는-이유">Suspense를 사용하는 이유<a class="anchor after" aria-hidden="true" tabindex="-1" href="#suspense를-사용하는-이유"><span class="anchor-icon">#</span></a></h2>
<p>Suspense를 적절한 곳에 잘 사용한다면 사용자 경험 향상뿐만 아니라 개발자 경험도 향상할 수 있습니다. Suspense가 주는 몇 가지 이점을 살펴보도록 하겠습니다.</p>
<h3 id="데이터-로딩-처리">데이터 로딩 처리<a class="anchor after" aria-hidden="true" tabindex="-1" href="#데이터-로딩-처리"><span class="anchor-icon">#</span></a></h3>
<p>CSR(Client Side Rendering)로 개발하다 보면 네트워크를 통해 데이터를 가져올 때 데이터를 응답받을 때까지 걸리는 시간 때문에 화면이 덜그럭 거리는 현상을 종종 접하게 됩니다. Suspense를 사용하면 데이터를 가져오는 동안에 스켈레톤 UI와 같은 로딩 컴포넌트를 사용자에게 노출하여 아래 그림과 같이 화면이 덜그럭 거리는 어색함을 줄일 수 있습니다.</p>

<p>번들러의 기능을 사용하여 여러 컴포넌트를 하나의 청크 파일로 묶을 수 있습니다. Webpack의 경우 아래 코드와 같이 <code>webpackChunkName</code>을 사용하면 하나의 청크 파일 안에 여러 컴포넌트를 묶을 수 있습니다.</p>

<h2 id="suspense-사용-시-주의사항">Suspense 사용 시 주의사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#suspense-사용-시-주의사항"><span class="anchor-icon">#</span></a></h2>
<p>Suspense를 사용할 때 주의해야 할 내용들을 살펴보도록 하겠습니다.</p>
