<p>Vue.js 디렉티브는 객체 안에 있는 각각의 라이프 사이클 함수는 서로 다른 스코프를 가지고 있기 때문에 각각의 라이프 사이클 함수에서 정의한 변수는 공유되지 않습니다. <code>duration</code>, <code>handleMousedown</code>, <code>handleMouseup</code>는 값을 업데이트하기 위해, 이벤트 리스너를 해제하기 위해 라이프 사이클 함수 간에 공유가 되어야 합니다. node의 하위 속성으로 정의하여 공유하는 방법을 사용했습니다.</p>

<h3 id="생성-및-사용-방법">생성 및 사용 방법<a class="anchor after" aria-hidden="true" tabindex="-1" href="#생성-및-사용-방법"><span class="anchor-icon">#</span></a></h3>
<p>Vue.js는 <code>Vue.directive</code> 함수에 디렉티브 이름과 정의한 디렉티브를 파라미터로 전달해야 합니다. <code>v-디렉티브 이름="파라미터"</code> 형태로 사용하면 됩니다. Svelte는 액션을 만들고 <code>use:액션 이름={파라미터}</code>형태로 사용하면 됩니다.</p>
<h3 id="object-vs-function">Object VS Function<a class="anchor after" aria-hidden="true" tabindex="-1" href="#object-vs-function"><span class="anchor-icon">#</span></a></h3>
<p>Vue.js에서 디렉티브는 라이프 사이클 함수를 속성으로 가지는 객체입니다. Svelte에서 액션은 함수입니다. 파라미터로 HTML 요소와 액션 디렉티브에서 전달받은 파라미터를 가지고, 라이프 사이클 함수를 속성으로 가지는 객체를 리턴합니다. 자세한 내용은 <a href="/tech/svelte/action/#action-%ED%95%A8%EC%88%98">액션 함수</a>에서 말씀드리도록 하겠습니다.</p>
<h3 id="라이프-사이클">라이프 사이클<a class="anchor after" aria-hidden="true" tabindex="-1" href="#라이프-사이클"><span class="anchor-icon">#</span></a></h3>
<p>Vue.js의 디렉티브는 <code>bind</code>, <code>inserted</code>, <code>update</code>, <code>componentUpdated</code>, <code>unbind</code> 5개의 라이프 사이클 함수를 가집니다. Svelte의 액션의 함수 본문에는 마운트 될 때의 동작을 정의하고, Vue.js보다 단순한 <code>update</code>, <code>destroy</code> 2개의 라이프 사이클 함수를 속성으로 가지는 객체를 리턴합니다. 자세한 내용은 <a href="/tech/svelte/action/#%EB%9D%BC%EC%9D%B4%ED%94%84-%EC%82%AC%EC%9D%B4%ED%81%B4-1">액션 라이프 사이클</a>에서 말씀드리도록 하겠습니다.</p>
<h2 id="action-함수">Action 함수<a class="anchor after" aria-hidden="true" tabindex="-1" href="#action-함수"><span class="anchor-icon">#</span></a></h2>
<p>액션 함수의 형태는 아래와 같습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">action</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">node</span><span style="color:#A0111F;--shiki-dark:#FF9492">:</span><span style="color:#702C00;--shiki-dark:#FFB757"> HTMLElement</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#702C00;--shiki-dark:#FFB757">parameters</span><span style="color:#A0111F;--shiki-dark:#FF9492">:</span><span style="color:#023B95;--shiki-dark:#91CBFF"> any</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) </span><span style="color:#A0111F;--shiki-dark:#FF9492">=></span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  update</span><span style="color:#A0111F;--shiki-dark:#FF9492">?:</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#702C00;--shiki-dark:#FFB757">parameters</span><span style="color:#A0111F;--shiki-dark:#FF9492">:</span><span style="color:#023B95;--shiki-dark:#91CBFF"> any</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) </span><span style="color:#A0111F;--shiki-dark:#FF9492">=></span><span style="color:#A0111F;--shiki-dark:#FF9492"> void</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">,</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  destroy</span><span style="color:#A0111F;--shiki-dark:#FF9492">?:</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> () </span><span style="color:#A0111F;--shiki-dark:#FF9492">=></span><span style="color:#A0111F;--shiki-dark:#FF9492"> void</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<h3 id="파라미터">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터"><span class="anchor-icon">#</span></a></h3>
<p>액션 함수는 2개의 파라미터를 가집니다.</p>
<ul>
<li><code>node</code>: 첫 번째 파라미터는 액션이 선언된 HTML 요소입니다.</li>
<li><code>parameters</code>: 두 번째 파라미터는 <code>use:액션 이름={parameters}</code>로 전달되는 <code>parameters</code>입니다.</li>
</ul>
<h3 id="리턴-값">리턴 값<a class="anchor after" aria-hidden="true" tabindex="-1" href="#리턴-값"><span class="anchor-icon">#</span></a></h3>
<p>액션 함수는 <code>update</code>와 <code>destroy</code> 속성을 가지는 객체를 리턴해야 합니다. <code>update</code>와 <code>destroy</code>는 함수로 액션의 라이프 사이클 함수입니다.</p>
<h3 id="라이프-사이클-1">라이프 사이클<a class="anchor after" aria-hidden="true" tabindex="-1" href="#라이프-사이클-1"><span class="anchor-icon">#</span></a></h3>
<p>액션의 라이프 사이클을 살펴보도록 하겠습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">function</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> foo</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#702C00;--shiki-dark:#FFB757">node</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#702C00;--shiki-dark:#FFB757">bar</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // the node has been mounted in the DOM</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  return</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    update</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#702C00;--shiki-dark:#FFB757">bar</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">      // the value of `bar` has changed</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    },</span></span>
<span class="line"></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    destroy</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">() {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">      // the node has been removed from the DOM</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  };</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<ul>
<li>update: <code>update</code> 라이프 사이클 함수는 액션이 선언된 DOM이 마운트 된 후 액션의 파라미터가 변경될 때마다 호출됩니다.</li>
<li>destroy: <code>destroy</code> 라이프 사이클 함수는 액션이 선언된 DOM이 제거되기 직전에 호출됩니다. 할당받은 자원을 이 라이프 사이클 함수에서 해제해야 합니다.</li>
<li>mount: 액션이 선언된 DOM이 마운트 된 후 동작해야 할 코드가 있다면 함수의 본문에 선언하면 됩니다.</li>
</ul>
