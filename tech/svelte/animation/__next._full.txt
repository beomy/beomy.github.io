<p>위의 예제와 <a href="/tech/svelte/transitions#crossfade-%ED%8A%B8%EB%9E%9C%EC%A7%80%EC%85%98"><code>crossfade</code> 디렉티브</a> 예제는 애니메이션 디렉티브인 <code>animate:flip</code>가 추가되었다는 부분만 차이가 있습니다.</p>
<p><code>flip</code>은 <a href="https://aerotwist.com/blog/flip-your-animations/">First, Last, Invert, Play</a>의 약어로 애니메이션 기법 중 하나입니다. 단순히 말하면, <code>filp</code>은 시작 위치와 마지막 위치를 계산하고 애니메이션을 적용하여 <code>x</code> 및 <code>y</code>를 변환합니다.</p>
<h4 id="파라미터">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터"><span class="anchor-icon">#</span></a></h4>
<p><code>flip</code> 함수는 아래와 같은 파라미터를 가집니다.</p>
<ul>
<li><code>delay</code> (number, default 0): 단위는 ms로 설정한 시간이 지난 후에 애니메이션을 시작합니다.</li>
<li><code>duration</code> (number | function, default: <code>d => Math.sqrt(d) * 120</code>): 숫자 혹은 함수가 올 수 있습니다.
<ul>
<li><code>number</code>: 단위는 ms입니다.</li>
<li><code>function</code>: <code>distance: number => duration: number</code> 형태의 함수가 와야 합니다. <code>distance</code>는 애니메이션으로 움직여야 할 픽셀입니다. 함수의 리턴 값은 ms 단위의 지속시간입니다.</li>
</ul>
</li>
<li><code>easing</code> (function, default cubicOut): easing 함수입니다. <a href="https://svelte.dev/docs#svelte_easing">https://svelte.dev/docs#svelte_easing</a> 참고 바랍니다.</li>
</ul>

<h4 id="파라미터-1">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터-1"><span class="anchor-icon">#</span></a></h4>
<p>애니메이션 함수는 3개의 파라미터를 가집니다.</p>
<ul>
<li><code>node</code>: 첫 번째 파라미터는 애니메이션이 적용되는 HTML 요소입니다.</li>
<li><code>{ from: DOMRect, to: DOMRect }</code>: 두 번째 파라미터는 애니메이션을 시작될 때의 정보 <code>from</code>과 애니메이션이 끝날 때의 정보 <code>to</code>를 속성으로 가지는 객체입니다.
<ul>
<li><code>DOMRect</code>: 애니메이션이 적용되는 요소의 위치 크기 등의 정보를 가지는 객체입니다.</li>
</ul>
</li>
<li><code>params</code>: 세 번째 파라미터는 <code>animate:애니메이션 이름={params}</code>의 <code>params</code>로 전달될 값입니다. 모든 형태의 값을 전달할 수 있습니다.</li>
</ul>
<h4 id="리턴-값">리턴 값<a class="anchor after" aria-hidden="true" tabindex="-1" href="#리턴-값"><span class="anchor-icon">#</span></a></h4>
<p>애니메이션 함수는 객체를 리턴해야 합니다. 리턴하는 객체는 아래의 속성을 가져야 하는데, 트랜지션 함수의 객체와 동일합니다.</p>
<ul>
<li><code>delay</code>: 단위는 ms로 설정한 시간이 지난 후에 애니메이션을 시작합니다.</li>
<li><code>duration</code>: 단위는 ms로 설정한 시간 동안 애니메이션이 동작합니다.</li>
<li><code>easing</code>: <code>p => t</code> 형태의 easing 함수입니다. <a href="https://svelte.dev/docs#svelte_easing">https://svelte.dev/docs#svelte_easing</a> 참고 바랍니다.</li>
<li><code>css</code>: <code>(t, u) => css</code> 함수입니다. <code>t</code>는 0 ~ 1 사이의 값이고, <code>u</code>는 <code>u === 1 - t</code>입니다. 요소가 추가될 때 <code>t</code>는 0에서 1로 증가하고, 요소가 제거될 때 <code>t</code>는 1에서 0으로 감소합니다. <code>t</code>(혹은 <code>u</code>)의 변화에 따른 CSS 문자열을 리턴해야 합니다.</li>
<li><code>tick</code>: <code>(t, u) => {...}</code> 함수입니다. 매 tick마다 호출되는 콜백 함수입니다.</li>
</ul>
<h2 id="애니메이션-사용-시-주의사항">애니메이션 사용 시 주의사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#애니메이션-사용-시-주의사항"><span class="anchor-icon">#</span></a></h2>
<p>애니메이션을 사용할 때 몇 가지 주의사항들을 살펴보겠습니다.</p>
<h3 id="key가-있는-each-블록-안에서-사용">key가 있는 <code>each</code> 블록 안에서 사용<a class="anchor after" aria-hidden="true" tabindex="-1" href="#key가-있는-each-블록-안에서-사용"><span class="anchor-icon">#</span></a></h3>
<p>key가 정의된 <code>each</code> 블록 안에서 애니메이션이 동작합니다. <code>{#each todos.filter(t => t.done) as todo (todo.id)}</code> 와 같이 key가 정의된 <code>each</code> 블록 내부에서 애니메이션 디렉티브를 사용해야 합니다.</p>
<h3 id="배열이-재정렬-될-때-트리거-됨">배열이 재정렬 될 때 트리거 됨<a class="anchor after" aria-hidden="true" tabindex="-1" href="#배열이-재정렬-될-때-트리거-됨"><span class="anchor-icon">#</span></a></h3>
<p><code>each</code> 블록의 배열이 재정렬 될 때에만 애니메이션이 동작합니다. 즉,</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">&#x3C;!-- When `list` is reordered the animation will run--></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{#each list as item, index (item)}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">li</span><span style="color:#023B95;--shiki-dark:#91CBFF"> animate:flip</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>{item}&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">li</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{/each}</span></span></code></pre>
<p>위의 코드의 <code>list</code>가 재정렬 될 때 애니메이션이 동작합니다.</p>
<h3 id="each-블록-직계-요소에-사용"><code>each</code> 블록 직계 요소에 사용<a class="anchor after" aria-hidden="true" tabindex="-1" href="#each-블록-직계-요소에-사용"><span class="anchor-icon">#</span></a></h3>
<p>애니메이션 디렉티브는 key가 정의된 <code>each</code> 블록의 직계 자식 요소에 정의되어야 합니다.</p>
