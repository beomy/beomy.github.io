<h3 id="속성-약어">속성 약어<a class="anchor after" aria-hidden="true" tabindex="-1" href="#속성-약어"><span class="anchor-icon">#</span></a></h3>
<p>Svelte는 간략한 코드를 더욱 간략하게 할 수 있도록 속성 약어를 제공합니다. 약어는 아래 코드와 같이 사용할 수 있습니다.</p>

<h3 id="class-속성-약어"><code>class</code> 속성 약어<a class="anchor after" aria-hidden="true" tabindex="-1" href="#class-속성-약어"><span class="anchor-icon">#</span></a></h3>
<p>HTML 요소의 속성 중 <code>class</code> 속성은 자주 사용되는 속성 중 하나입니다. Svelte는 <code>class</code> 속성 약어 기능을 제공합니다.</p>
<p>Svelte에서 HTML 요소에 <code>class</code> 속성을 주고 싶을 때, 보통 아래와 같이 사용합니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">button</span></span>

<h2 id="스타일-정의">스타일 정의<a class="anchor after" aria-hidden="true" tabindex="-1" href="#스타일-정의"><span class="anchor-icon">#</span></a></h2>
<p>스타일을 정의하는 방법은 Vue.js와 유사합니다. 스타일은 아래 코드와 같이 정의할 수 있습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    color</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#023B95;--shiki-dark:#91CBFF">purple</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    font-family</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">'Comic Sans MS'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, cursive;</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    font-size</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#023B95;--shiki-dark:#91CBFF">2</span><span style="color:#A0111F;--shiki-dark:#FF9492">em</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>This is a paragraph.&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span></code></pre>
<p><del>Vue.js와 Svelte의 차이는 Vue.js에서는 <code>&#x3C;style scoped></code>이라고 명시를 해 줘야 로컬(local) 스타일이 되지만, Svelte에서는 기본 값이이 로컬 스타일입니다. Svelte에서 글로벌(global) 스타일을 지정하기 위해서는 <code>&#x3C;style global></code>로 명시해 주어야 합니다.</del> (Outdated 되었습니다.)</p>
<h3 id="global"><code>:global</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#global"><span class="anchor-icon">#</span></a></h3>
<p>전역 스타일을 지정하기 위해서는 <code>:global</code>을 사용해야 합니다. 사용 방법은 Vue.js의 <code>v-deep</code>과 유사합니다. Vue.js의 <code>v-deep</code>은 아래 코드와 같이 사용할 수 있습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">template</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>HELLOW WORLD&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">template</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#023B95;--shiki-dark:#91CBFF"> scoped</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> ::</span><span style="color:#024C1A;--shiki-dark:#72F088">v-deep</span><span style="color:#024C1A;--shiki-dark:#72F088"> h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    color</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#023B95;--shiki-dark:#91CBFF">red</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span></code></pre>
<p>Svelte에서는 아래와 같이 사용할 수 있습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>HELLOW WORLD&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> :global(</span><span style="color:#024C1A;--shiki-dark:#72F088">h1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    color</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#023B95;--shiki-dark:#91CBFF">red</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span></code></pre>
<p>위의 코드처럼 작성하면 해당 컴포넌트의 <code>div</code> 안에 있는 모든 <code>h1</code>(하위 컴포넌트에 사용했더라도)은 <code>color:red</code> 스타일이 적용됩니다.</p>

<h2 id="html-문자열-표현">HTML 문자열 표현<a class="anchor after" aria-hidden="true" tabindex="-1" href="#html-문자열-표현"><span class="anchor-icon">#</span></a></h2>
