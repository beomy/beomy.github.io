<h2 id="input"><code>input</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#input"><span class="anchor-icon">#</span></a></h2>

<p>위의 Svelte 코드는 많은 기능을 사용한 코드입니다.</p>
<ul>
<li><code>add</code>와 <code>clear</code> 함수는 반응형 동작을 위해 <code>todos</code>를 재할당 합니다.</li>
<li><code>$:</code>는 <code>todos</code>가 변경되었을 때 실행됩니다. <code>!done</code>인 <code>todos</code>의 개수를 <code>remaining</code>에 저장합니다.</li>
<li><code>class:done</code>은 <code>todo.done</code>이 ture일 경우 <code>done</code> 클래스가 추가됩니다.</li>
<li><code>{#each todos as todo, index (index)}</code> 블록 내에 <code>bind:checked</code>와 <code>bind:value</code>를 사용하여 <code>todos</code>의 변경 내용이 반영합니다. Vue.js에서 <code>v-for</code> 블록문 안에 <code>v-model</code>을 사용하는 것과 유사합니다. Svelte는 <code>{# each}</code> 블록문 안에 <code>bind:속성 이름</code>으로 블록문 안에서 데이터 바인딩 할 수 있습니다.</li>
</ul>
