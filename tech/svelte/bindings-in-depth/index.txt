<h3 id="8가지-readonly-속성">8가지 Readonly 속성<a class="anchor after" aria-hidden="true" tabindex="-1" href="#8가지-readonly-속성"><span class="anchor-icon">#</span></a></h3>

<ul>
<li><code>duration</code> <em>Number</em> (readonly): 총 재생 길이(초 단위)</li>
<li><code>buffered</code> <em>Array</em> (readonly): <code>{start, end}</code> 객체들의 배열로, 버퍼 된 위치를 표시함</li>

<li><code>played</code> <em>Array</em> (readonly): <code>{start, end}</code> 객체들의 배열로, 재생했던 위치들을 표시함</li>
<li><code>seeking</code> <em>Boolean</em> (readonly): 찾는 중인지를 표시하는 플래그</li>
<li><code>ended</code> <em>Boolean</em> (readonly): 재생이 끝났는지를 표시하는 플래그</li>
<li><code>videoWidth</code> <em>Number</em> (readonly): <code>&#x3C;video></code> 태그에서 사용할 수 있는 속성으로 <code>&#x3C;video></code> 태그의 너비를 나타냄.</li>
<li><code>videoHegiht</code> <em>Number</em> (readonly): <code>&#x3C;video></code> 태그에서 사용할 수 있는 속성으로 <code>&#x3C;video></code> 태그의 높이를 나타냄.</li>
</ul>

<h3 id="주의사항">주의사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#주의사항"><span class="anchor-icon">#</span></a></h3>
<p><code>clientWidth</code>, <code>clientHeight</code>, <code>offsetWidth</code>, <code>offsetHeight</code> 속성을 바인딩 하여 사용할 때 주의해야 할 몇 가지 내용들이 있습니다.</p>
<h4 id="성능-이슈">성능 이슈<a class="anchor after" aria-hidden="true" tabindex="-1" href="#성능-이슈"><span class="anchor-icon">#</span></a></h4>
<p>위의 4가지 속성을 바인딩하고 사용하는 것은 성능상 오버헤드가 발생하기 때문에 많은 요소에 사용하는 것을 추천하지 않습니다.</p>
<h4 id="바인딩-할-수-없는-태그들">바인딩 할 수 없는 태그들<a class="anchor after" aria-hidden="true" tabindex="-1" href="#바인딩-할-수-없는-태그들"><span class="anchor-icon">#</span></a></h4>
<p><code>display:inline</code> 스타일 사용하는 태그나, <code>&#x3C;span></code> 등의 인라인 요소들에는 바인딩 할 수 없습니다. <code>&#x3C;canvas></code>와 같이 다른 태그들을 포함할 수 없는 태그에도 사용할 수 없습니다.</p>
<p>바인딩 할 수 없는 태그들에 위의 4가지 속성을 바인딩 해야 한다면 블록 레벨 요소로 감싸고 그 블록 레벨 요소에 바인딩 하여 사용해야 합니다.</p>
<h2 id="this-바인딩"><code>this</code> 바인딩<a class="anchor after" aria-hidden="true" tabindex="-1" href="#this-바인딩"><span class="anchor-icon">#</span></a></h2>
<p>이번에는 <code>this</code>를 바인딩 하는 방법을 살펴보도록 하겠습니다. Svelte에서 <code>this</code>를 바인딩 하는 것은 Vue.js에서 <code>ref</code>를 사용하는 것과 유사합니다.</p>
<p>Vue.js에서 <code>ref</code>를 HTML 태그와 컴포넌트 모두 사용 가능한 것처럼 Svelte에서도 HTML 태그와 컴포넌트 모두 <code>this</code>를 바인딩 할 수 있습니다. HTML 태그에 <code>this</code>를 바인딩 할 경우 HTML 요소가 바인딩 되고, 컴포넌트에 <code>this</code>를 바인딩 한 경우 컴포넌트가 바인딩 됩니다.</p>

<p>컴포넌트가 마운트 된 후에 <code>canvas</code> 변수에 값이 할당되기 때문에, <code>onMount</code>라는 라이프 사이클을 사용했습니다. 라이프 사이클은 이후 포스팅에서 좀 더 자세히 알아보도록 하겠습니다. 지금은 컴포넌트가 화면에 마운트 될 때 호출되는 콜백으로 이해하시면 됩니다. <code>onMount</code> 콜백 함수에서 리턴되는 함수는 컴포넌트가 제거되었을 때 호출됩니다.</p>
<p>Vue.js에서는 <code>&#x3C;canvas ref="canvas"></code>로 태그를 선언하고, <code>&#x3C;canvas></code> 태그에 접근할 때는 <code>this.$refs.canvas</code>로 접근할 수 있습니다.</p>
<p>Svelte에서는 <code>&#x3C;script></code> 태그 안에 <code>let canvas</code>로 <code>canvas</code> 변수를 정의한 후, <code>&#x3C;canvas bind:this="{canvas}"></code>로 태그를 선언하고, <code>&#x3C;canvas></code> 태그에 접근할 때는 <code>canvas</code> 변수를 통해 접근할 수 있습니다.</p>

<p>Svelte에서는 컴포넌트의 props를 바인딩 하는데 Vue.js의 <code>.sync</code>와 같은 특별한 문법이 사용할 필요 없습니다. DOM 속성을 바인딩 할 때처럼 <code>bind:바인딩 속성</code>을 사용하여 컴포넌트의 props를 바인딩 할 수 있습니다.</p>
<h3 id="주의사항-1">주의사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#주의사항-1"><span class="anchor-icon">#</span></a></h3>
