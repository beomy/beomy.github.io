<p>일부 프레임워크에서는 성능상의 이유로 인라인 이벤트 핸들러 사용을 피하라고 추천합니다. 하지만 Svelte는 컴파일되면서 최적화되기 때문에 인라인 핸들러를 사용해야 할 때는 성능의 고민 없이 사용하면 됩니다.</p>

<h3 id="수식어-목록">수식어 목록<a class="anchor after" aria-hidden="true" tabindex="-1" href="#수식어-목록"><span class="anchor-icon">#</span></a></h3>
<p>이벤트 수식어 목록은 아래와 같습니다.</p>
<ul>
<li><code>preventDefault</code>: 이벤트 핸들러가 실행되기 전 <code>event.preventDefault()</code>를 호출합니다. 태그의 기본 동작을 막는 이벤트 수식어입니다.</li>
<li><code>stopPropagation</code>: <code>event.stopPropagation()</code>이 호출됩니다. 이벤트가 다음 요소로 흐르는 것을 막는 이벤트 수식어입니다.</li>
<li><code>passive</code>: 터치 혹은 휠 이벤트로 발생하는 스크롤 성능을 향상시키는 이벤트 수식어입니다. Svelte는 안전한 곳(?)에 자동으로 추가합니다.</li>
<li><code>capture</code>: 버블링 단계가 아닌 캡처 단계에서 이벤트 핸들러를 실행합니다.</li>
<li><code>once</code>: 이벤트 핸들러를 단 한 번만 실행하도록 하는 이벤트 수식어입니다.</li>
<li><code>self</code>: <code>event.target</code>과 이벤트 핸들러를 정의한 요소가 같을 때 이벤트 핸들러를 실행하도록 하는 이벤트 수식어입니다.</li>
</ul>
<p>위의 이벤트 수식어를 <code>on:click|once|capture={...}</code>와 같이 체인(chain)으로 연결해 여러 개를 정의할 수도 있습니다.</p>

<h3 id="createeventdispatcher-호출-시-주의-사항"><code>createEventDispatcher</code> 호출 시 주의 사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#createeventdispatcher-호출-시-주의-사항"><span class="anchor-icon">#</span></a></h3>
<p><code>createEventDispatcher</code>는 컴포넌트가 처음 인스턴스화될 때 선언되어야 합니다. 예를 들어 <code>setTimeout</code>의 콜백 함수에서 <code>createEventDispatcher</code>를 호출하는 것처럼 나중에 호출할 수 없습니다.</p>
<h3 id="이벤트-포워딩">이벤트 포워딩<a class="anchor after" aria-hidden="true" tabindex="-1" href="#이벤트-포워딩"><span class="anchor-icon">#</span></a></h3>
<p>DOM 이벤트와는 달리 컴포넌트 이벤트는 버블(bubble) 되지 않습니다. 버블 되지 않는다는 의미는 하위 컴포넌트의 이벤트가 자동으로 상위 컴포넌트로 전달되지 않는다는 의미입니다. 의도적으로 상위 컴포넌트로 이벤트를 전달해야 합니다. (Vue.js를 사용해 왔다면, 당연한 이야기 일 수 있습니다.)</p>
<p>App 컴포넌트와 Outer 컴포넌트, Inner 컴포넌트를 정의하여 Inner 컴포넌트의 이벤트를 App 컴포넌트로 전달하는 방법을 알아보도록 하겠습니다. Vue.js에서는 아래와 같이 구현할 수 있습니다.</p>
