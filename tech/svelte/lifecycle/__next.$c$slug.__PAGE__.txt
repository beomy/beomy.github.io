6:T12c59,<p>이번 포스트에서는 컴포넌트의 생명주기(Lifecycle)를 이야기할 것입니다. 생명주기를 라이프 사이클이라고도 하는데, 앞으로는 생명주기라는 단어 대신 라이프 사이클이라는 단어를 사용하도록 하겠습니다.</p>
<p>라이프 사이클 함수란 컴포넌트가 화면에 마운트(화면에 출력) 되거나, 화면이 업데이트 혹은 화면에서 언 마운트(화면에서 제거) 됐을 때 실행되는 콜백 함수들을 말합니다.</p>
<p>Vue.js의 라이프 사이클 함수는 <code>beforeCreate</code>, <code>created</code>, <code>beforeMount</code>, <code>mounted</code>, <code>beforeUpdate</code>, <code>updated</code>, <code>beforeDestroy</code>, <code>destroyed</code> 8가지가 있습니다. Svelte는 Vue.js보다 더 단순한 <code>onMount</code>, <code>onDestroy</code>, <code>beforeUpdate</code>, <code>afterUpdate</code> 4가지 종류로 되어 있습니다.</p>
<p>Svelte의 라이프 사이클 함수들은 <code>import { 라이프 사이클 함수 이름 } from 'svelte'</code>로 라이프 사이클 함수를 가져올 수 있습니다.</p>
<h2 id="onmount"><code>onMount</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#onmount"><span class="anchor-icon">#</span></a></h2>
<p>가장 많이 사용되는 라이프 사이클 함수는 <code>onMount</code> 함수입니다. 이 함수는 컴포넌트가 처음으로 DOM에 렌더링 될 때 실행되는 함수입니다. 네트워크를 통해 데이터를 가져와야 할 경우 <code>onMount</code>를 사용하는 것이 좋습니다. Vue.js의 <code>mounted</code> 라이프 사이클 함수와 유사합니다.</p>
<p>Vue.js에서 네트워크를 통해 데이터를 가져와야 할 경우 <code>created</code> 라이프 사이클 함수를 사용할 수도 있지만, 마운트 된 후 데이터를 가져오는 것을 알아보기 위해 <code>mounted</code> 라이프 사이클 함수에서 데이터를 가져와 보도록 하겠습니다. Vue.js에서는 <code>mounted</code> 라이프 사이클 함수를 아래와 같이 사용합니다.</p>

<h3 id="네트워크-작업은-onmount에서">네트워크 작업은 <code>onMount</code>에서<a class="anchor after" aria-hidden="true" tabindex="-1" href="#네트워크-작업은-onmount에서"><span class="anchor-icon">#</span></a></h3>
<p>네트워크를 통해 데이터를 가져와 느리게 데이터가 세팅이 된다면, <code>&#x3C;script></code> 태그의 상단이 아닌 <code>onMount</code> 라이프 사이클 함수에서 가져오는 것이 좋습니다.</p>
<p>서버 사이드 랜더링(Server Side Rendering) 중에는, <code>onDestroy</code> 라이프 사이클 함수를 제외한 다른 라이프 사이클 함수들은 실행되지 않습니다. 서버 사이드 랜더링되는 동안에 <code>onMount</code> 라이프 사이클 함수가 실행되지 않기 때문에, 마운트 된 후에 실행되는 <code>onMount</code>에서 데이터를 가져오면, 데이터를 가져오느라 DOM이 느리게 마운트 되는 문제를 피할 수 있습니다.</p>
<h3 id="onmount-파라미터의-함수-리턴"><code>onMount</code> 파라미터의 함수 리턴<a class="anchor after" aria-hidden="true" tabindex="-1" href="#onmount-파라미터의-함수-리턴"><span class="anchor-icon">#</span></a></h3>
<p><code>onMount</code> 파라미터의 리턴 값이 함수가 전달되면, 이 함수는 컴포넌트가 DOM에서 언 마운트 될 때 실행됩니다. 이 예제는 <a href="/tech/svelte/bindings-in-depth/#this-%EB%B0%94%EC%9D%B8%EB%94%A9">[Svelte] 데이터 바인딩 고급-this 바인딩</a>에서 한번 살펴보았습니다.</p>
<h2 id="ondestroy"><code>onDestroy</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#ondestroy"><span class="anchor-icon">#</span></a></h2>

<h2 id="tick"><code>tick</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#tick"><span class="anchor-icon">#</span></a></h2>
<p><code>tick</code>은 다른 라이프 사이클 함수들과 다르게 언제든 사용할 수 있습니다. 언제든 사용할 수 있다는 뜻은 마운트 된 후에만 호출되는 <code>onMount</code>, 제거된 후에만 호출되는 <code>onDestroy</code> 와는 달리 언제든 호출된다는 뜻입니다. <code>tick</code> 함수는 변경된 내용이 있다면 변경된 내용이 DOM에 반영된 직후에, 변경된 내용이 없다면 바로 호출됩니다.</p>
<p>Svelte는 상태가 변경되면 즉시 업데이트되지 않습니다. 정해진 시간 동안에 변경된 내용들을 한꺼번에 업데이트합니다. 이런 동작은 불필요한 작업을 피할 수 있으며, 브라우저가 효율적으로 작업을 일괄 처리할 수 있게 됩니다.</p>
<p><code>&#x3C;textarea></code>에서 텍스트를 선택한 후 탭 키를 누를 경우, 소문자를 대문자로, 대문자를 소문자로 변경하는 예제로 <code>tick</code>을 살펴보도록 하겠습니다. 아래 코드는 Vue.js로 구현한 예제입니다.</p>
