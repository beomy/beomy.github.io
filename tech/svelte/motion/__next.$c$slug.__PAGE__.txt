<h3 id="tweened-함수"><code>tweened</code> 함수<a class="anchor after" aria-hidden="true" tabindex="-1" href="#tweened-함수"><span class="anchor-icon">#</span></a></h3>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">store </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> tweened</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(value: any, options)</span></span></code></pre>
<p><code>tweened</code> 함수는 2개의 파라미터를 가집니다. 첫 번째 파라미터는 변경되는 값이고 두 번째 파라미터는 옵션입니다. <code>tweened</code> 함수는 store를 리턴합니다. <code>options</code>에 설정할 수 있는 값을 살펴보겠습니다.</p>
<ul>
<li><code>delay</code> (number, default 0): 단위는 ms로, 설정한 시간 후에 시작됩니다.</li>
<li><code>duration</code> (number, default 400): 단위는 ms로, 설정한 시간 동안 실행됩니다.</li>
<li><code>easing</code> (function, default t => t): <code>easing</code> 함수입니다. Svelte는 기본으로 30가지 템플릿(<a href="https://svelte.dev/docs#svelte_easing">https://svelte.dev/docs#svelte_easing</a> 참고)을 제공합니다. 커스텀 하게 만들 수도 있습니다.</li>
<li><code>interpolate</code> (function): 두 값 사이를 보간하여 좀 더 부드럽게 보여주기 위해서 사용되는 옵션입니다. <code>(a, b) => t => value</code> 형태가 와야 합니다. <code>a</code>는 시작 값, <code>b</code>는 목푯값, <code>t</code>는 0과 1사이의 숫자이고, <code>value</code>는 결과 값입니다.</li>
</ul>
<p><code>store.set</code>과 <code>store.update</code>의 두 번째 파라미터에 <code>options</code>(위에서 설명한 옵션)를 전달할 수 있습니다. 전달된 옵션은 기본값(인스턴스를 생성할 때 사용한 <code>tweened(value, options)</code>의 <code>options</code>가 기본값입니다.)에 오버라이드(override) 됩니다. <code>set</code>과 <code>update</code> 함수의 리턴 값은 Promise입니다. tween 작업이 완료되면 Promise가 resolve 됩니다.</p>

<p>위의 코드와 그림은 <code>spring</code> Motion을 사용하여 커서의 위치를 나타내는 원과 클릭 이벤트에 따라 원의 크기가 바뀌는 예제 코드와 결과입니다. <code>spring</code> 함수를 살펴보도록 하겠습니다.</p>
<h3 id="spring-함수"><code>spring</code> 함수<a class="anchor after" aria-hidden="true" tabindex="-1" href="#spring-함수"><span class="anchor-icon">#</span></a></h3>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">store </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> spring</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(value: any, options)</span></span></code></pre>
<p><code>spring</code> 함수는 2개의 파라미터를 가집니다. 첫 번째 파라미터는 변경되는 값이고 두 번째 파라미터는 옵션입니다. <code>spring</code> 함수는 store를 리턴합니다. <code>options</code>에 설정할 수 있는 값을 살펴보겠습니다.</p>
<ul>
<li><code>stiffness</code> (number, default 0.15): 0과 1 사이의 값입니다. 값이 높을수록 즉시 Motion이 반영됩니다.
<img src="/assets/img/posts/svelte/cursor_stiffness.gif" alt="커서 이동" loading="lazy" decoding="async" width="1215" height="208" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/cursor_stiffness-opt-640.WEBP 640w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_stiffness-opt-1080.WEBP 1080w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_stiffness-opt-1920.WEBP 1920w" sizes="(max-width: 640px) 100vw, 1000px"></li>
<li><code>damping</code> (number, default 0.8): 0과 1 사이의 값입니다. 값이 낮을수록 스프링처럼 튕기는 Motion 범위가 넓어집니다.
<img src="/assets/img/posts/svelte/cursor_damping.gif" alt="커서 이동" loading="lazy" decoding="async" width="1215" height="208" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/cursor_damping-opt-640.WEBP 640w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_damping-opt-1080.WEBP 1080w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_damping-opt-1920.WEBP 1920w" sizes="(max-width: 640px) 100vw, 1000px"></li>
<li><code>precision</code> (number, default 0.001): 스프링처럼 튕기는 동작이 정착된(settled) 것으로 간주하는 임곗값(threshold)입니다. 쉽게 말해서 값이 클수록 스프링처럼 튕기는 횟수가 줄어들고, 값이 낮을수록 스프링처럼 튕기는 횟수가 증가합니다.
<img src="/assets/img/posts/svelte/cursor_precision.gif" alt="커서 이동" loading="lazy" decoding="async" width="1215" height="315" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/cursor_precision-opt-640.WEBP 640w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_precision-opt-1080.WEBP 1080w, /assets/img/posts/svelte/nextImageExportOptimizer/cursor_precision-opt-1920.WEBP 1920w" sizes="(max-width: 640px) 100vw, 1000px"></li>
</ul>
<p><code>store.stiffness</code>, <code>store.damping</code>, <code>store.precision</code> 속성을 변경할 수 있습니다. 변경되면 즉시 반영됩니다.</p>
<p><code>tweened</code> store와 동일하게, <code>set</code>과 <code>update</code> 함수를 제공합니다. <code>set</code>과 <code>update</code> 함수의 리턴 값은 Promise로 <code>spring</code> 동작이 완료되면 resolve 됩니다.</p>
<p><code>set</code>과 <code>update</code> 함수는 두 번째 파라미터를 가질 수 있습니다. 두 번째 파라미터는 <code>hard</code>나 <code>soft</code> 속성을 가지는 객체입니다. <code>{ hard: true }</code>을 전달하면 즉시 반영됩니다. <code>{ soft: n }</code>은 <code>n</code>초 후에 반영됩니다. <code>{ soft: ture }</code>는 <code>{ soft: 0.5 }</code>와 동일합니다.</p>
<h2 id="spring과-tweened-차이"><code>spring</code>과 <code>tweened</code> 차이<a class="anchor after" aria-hidden="true" tabindex="-1" href="#spring과-tweened-차이"><span class="anchor-icon">#</span></a></h2>
<p><code>spring</code> store의 값은 <code>stiffness</code>와 <code>damping</code>의 값에 따라 점차 변경됩니다.<code>tweened</code> store의 값은 고정된 <code>duration</code> 동안 변경되는 반면, <code>spring</code> store은 기본 속도에 의해 결정된 시간 동안 값이 변경되어 좀 더 자연스럽게 보이게 됩니다.</p>
