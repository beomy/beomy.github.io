<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">      addNumber</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> () {</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">        this</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">.number.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">push</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="color:#023B95;--shiki-dark:#91CBFF">this</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">.number.</span><span style="color:#023B95;--shiki-dark:#91CBFF">length</span><span style="color:#A0111F;--shiki-dark:#FF9492"> +</span><span style="color:#023B95;--shiki-dark:#91CBFF"> 1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">)</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">      }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    }</span></span>
<span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">  }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span></code></pre>
<p>위의 코드와 같이 Vue.js는 Array 메서드인 <code>push</code>를 사용하여 값을 변경되면 반응형이 동작합니다. 동일한 동작을 하는 Svelte 코드는 아래와 같습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> numbers </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> [</span><span style="color:#023B95;--shiki-dark:#91CBFF">1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#023B95;--shiki-dark:#91CBFF">2</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#023B95;--shiki-dark:#91CBFF">3</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#023B95;--shiki-dark:#91CBFF">4</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">];</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  function</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> addNumber</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">() {</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    numbers </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> [</span><span style="color:#A0111F;--shiki-dark:#FF9492">...</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">numbers, numbers.</span><span style="color:#023B95;--shiki-dark:#91CBFF">length</span><span style="color:#A0111F;--shiki-dark:#FF9492"> +</span><span style="color:#023B95;--shiki-dark:#91CBFF"> 1</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">];</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    /*</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    또는,</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    numbers.push(numbers.length + 1);</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    numbers = numbers;</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    또는,</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    numbers[numbers.length] = numbers.length + 1;</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    */</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"></span>
<span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">  $</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: sum </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> numbers.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">reduce</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">((</span><span style="color:#702C00;--shiki-dark:#FFB757">t</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#702C00;--shiki-dark:#FFB757">n</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">) </span><span style="color:#A0111F;--shiki-dark:#FF9492">=></span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> t </span><span style="color:#A0111F;--shiki-dark:#FF9492">+</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> n, </span><span style="color:#023B95;--shiki-dark:#91CBFF">0</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">);</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>{numbers.join(' + ')} = {sum}&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">button</span><span style="color:#023B95;--shiki-dark:#91CBFF"> on:click</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">{addNumber}</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  Add a number</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">button</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span></code></pre>
<p>위의 코드와 같이 Svelte는 변수에 재할당이 되어야 반응형이 동작합니다.</p>
<p>재할당 할 때 한 가지 규칙이 있습니다. 반응형으로 업데이트되어야 하는 변수가 재할당식에 왼쪽에 와야 합니다. 예를 들어 아래 코드는 반응형 동작을 하지 않습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> foo</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> obj.foo;</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">foo.bar </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'baz'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span></code></pre>
<p>반응형으로 업데이트되어야 하는 변수, <code>obj</code>가 재할당식에 왼쪽에 와야 반응형으로 동작을 할 수 있는데, 위의 코드의 경우 <code>foo</code>가 왼쪽에 있기 때문에 반응형 동작을 하지 않습니다. 위의 코드가 반응형으로 동작하기 위해서는,</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">obj.foo.bar </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'baz'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span></code></pre>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> foo</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> obj.foo;</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">foo.bar </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'baz'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">obj </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> obj;</span></span></code></pre>
<p>위의 코드와 같이 재할당식에 왼쪽에 <code>obj</code>가 오도록 수정해야 합니다.</p>
<h2 id="고찰">고찰<a class="anchor after" aria-hidden="true" tabindex="-1" href="#고찰"><span class="anchor-icon">#</span></a></h2>
<p>Vue.js를 사용하는 입장에서 Svelte를 사용하면서 느꼈던 단점들을 정리해보았습니다. 장점들도 많지만 단점들만 작성해 보았어요.</p>
<h3 id="코드-관리">코드 관리<a class="anchor after" aria-hidden="true" tabindex="-1" href="#코드-관리"><span class="anchor-icon">#</span></a></h3>
<p>Vue.js의 경우, 데이터는 <code>data</code> 속성에, 사용되는 함수들은 <code>methods</code> 속성에 그 밖에 <code>computed</code> 속성과 <code>watch</code> 속성이 있어 의도에 따라 코드를 분리할 수 있습니다. 반면에, Svelte는 <code>&#x3C;script></code> 태그 안에 이벤트 핸들러 함수와, 화면에 나타나는 데이터들, 혹은 화면에는 나타나지는 않지만 필요한 변수들 모두 정의됩니다. 프로젝트 규모가 커지고, 코드 양이 많아지면 Svelte의 경우 코드가 여기저기 나눠질 가능성이 있어 보였습니다.</p>
<h3 id="반응형-동작">반응형 동작<a class="anchor after" aria-hidden="true" tabindex="-1" href="#반응형-동작"><span class="anchor-icon">#</span></a></h3>
<p>반응형 동작의 경우에는 Vue.js는 <code>splice</code>, <code>sort</code>, <code>push</code>, <code>pop</code> 등의 Array 메서드를 사용하면 반응형이 동작하지만 Svelte의 경우에는 재할당이 일어나야만 반응형이 동작하기 때문에 익숙하지 않아 불편했습니다. 또한 Array 메서드를 사용하고도 재할당 코드를 작성해야 하는 불필요한 코드가 추가되는 단점이 있었습니다.</p>
