<h2 id="quick-start-guide">Quick Start Guide<a class="anchor after" aria-hidden="true" tabindex="-1" href="#quick-start-guide"><span class="anchor-icon">#</span></a></h2>
<p>Svelte 공식 문서에서 Svelte 프로젝트를 빠르게 만들 수 있는 2가지 방법(REPL과 digit)을 이야기합니다. REPL, digit으로 프로젝트를 만들수 있는 방법을 이야기하도록 하겠습니다. 자세한 내용은 <a href="https://svelte.dev/blog/the-easiest-way-to-get-started">quickstart guide</a>를 참고 바랍니다.</p>
<h3 id="repl-사용">REPL 사용<a class="anchor after" aria-hidden="true" tabindex="-1" href="#repl-사용"><span class="anchor-icon">#</span></a></h3>
<p><a href="https://ko.wikipedia.org/wiki/REPL">REPL(Real Eval Print Loop)</a>이란 사용자의 입력을 받아 실행하고 결과를 사용자에게 보여주는 프로그래밍 환경을 말합니다.</p>
<p><a href="/tech/svelte/introduction-svelte">Svelte 소개</a>에서 이야기한 것처럼 Svelte는 빌드 타임에 반응형이 결정됩니다. 이런 특징은 런타임 동안에 변경사항을 찾아야 하는 오버헤드를 줄여 속도를 개선하는 장점이 있지만, CDN 등으로 Svelte를 사용할 수 없는 단점도 있습니다. CDN으로 Svelte를 사용할 수 없어서 CodePen 등의 웹 IDE를 사용할 수 없습니다. Svelte는 이런 단점을 보완하기 위해 자체적으로 REPL을 제공하는 것으로 보입니다.</p>
<p><a href="https://svelte.dev/repl/hello-world?version=3.18.1">Svelte REPL</a>에서 코딩한 후 코딩한 프로젝트를 다운로드할 수 있습니다. <code>svelte-app.zip</code>으로 다운로드되는데, 파일의 압축을 풀고 아래와 같이 프로젝트를 실행할 수 있습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="bash"><code><span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">cd</span><span style="color:#032563;--shiki-dark:#ADDCFF"> /path/to/svelte-app</span></span>

<p>이 방법을 사용하면 rollup 번들러(bundler)를 사용한 프로젝트가 만들어집니다.</p>

<h2 id="개선사항">개선사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#개선사항"><span class="anchor-icon">#</span></a></h2>
<p>지금까지 sass와 typescript를 사용할 수 있도록 프로젝트를 구성하면서 몇 가지 추가되었으면 좋겠다 생각이 드는 부분이 있습니다.</p>
<ul>
<li><code>d.ts</code>로 타입을 만든 후 <code>.svelte</code> 내에서 생성한 타입을 사용하면 타입스크립트 에러가 발생합니다. 생성한 타입을 <code>.ts</code> 파일에서 사용하면 에러가 발생하지 않습니다. Svelte에서 타입스크립트를 지원하지 않아 발생한 문제인지, 다른 원인으로 발생하는지 파악하지 못했습니다.</li>
<li><code>$: 변수 = ...</code>나 <code>svelte/store</code>의 <code>$스토어명</code>과 같은 Svelte만의 독특한 문법이 있습니다. 타입스크립트에서 이런 문법은 에러로 잡아내는 문제가 있습니다.</li>
<li>Svelte의 템플릿 프로젝트 구조에는 eslint와 같은 정적 코드 분석 툴이 빠져 있습니다. 템플릿 프로젝트에 eslint가 추가되면 좋을 것 같습니다.</li>
</ul>
