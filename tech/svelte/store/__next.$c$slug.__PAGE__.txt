<p>위의 <code>count.update</code>의 <code>n</code>은 현재의 <code>count</code>가 관찰하고 있는 값을 저장하고 있습니다. <code>n => n + 1</code>은 <code>n + 1</code>을 리턴한다는 의미입니다. 리턴된 값으로 <code>count</code>가 관찰하는 값을 업데이트합니다. 즉, 이전에 관찰하는 값보다 1이 더 큰 값으로 업데이트됩니다.</p>
<p><code>writable(0)</code>로 <code>count</code> 변수를 생성하였기 때문에, <code>count</code>가 관찰하고 있는 값의 초깃값은 0이 됩니다.</p>

<h3 id="자동-구독">자동 구독<a class="anchor after" aria-hidden="true" tabindex="-1" href="#자동-구독"><span class="anchor-icon">#</span></a></h3>

<h4 id="주의사항">주의사항<a class="anchor after" aria-hidden="true" tabindex="-1" href="#주의사항"><span class="anchor-icon">#</span></a></h4>
<p>자동 구독 기능을 사용하려면 몇 가지 주의해야 할 내용들이 있습니다.</p>
<h5 id="store-변수-정의는-최상위-스코프에-있어야-합니다">store 변수 정의는 최상위 스코프에 있어야 합니다.<a class="anchor after" aria-hidden="true" tabindex="-1" href="#store-변수-정의는-최상위-스코프에-있어야-합니다"><span class="anchor-icon">#</span></a></h5>
<p>최상위 스코프에 있다는 것은, 블록 안에서 변수가 정의되지 않고 <code>&#x3C;scirpt></code> 태그 하위에 바로 정의되어야 하는 것을 의미합니다. <code>import</code> 된 store 변수 혹은 최상위 스코프에서 정의된 store 변수는 자동 구독을 할 수 있습니다.</p>
<h5 id="를-접두사로-사용하는-변수를-선언할-수-없습니다"><code>$</code>를 접두사로 사용하는 변수를 선언할 수 없습니다.<a class="anchor after" aria-hidden="true" tabindex="-1" href="#를-접두사로-사용하는-변수를-선언할-수-없습니다"><span class="anchor-icon">#</span></a></h5>
<p>자동 구독을 위해 <code>$</code> 접두사를 사용하기 때문에, Svelte는 <code>$</code> 접두사를 사용하는 변수 선언을 막았습니다.</p>

any)</span></span></code></pre>
<p><code>derived</code> 함수의 위의 4가지 형태를 지원합니다. <code>derived</code> 함수는 최대 3개의 파라미터를 가질 수 있습니다.</p>
<ul>
<li>첫 번째 파라미터는 참고하는 store입니다. 참고하는 store가 하나라면 <code>derived(a, ...)</code>으로 객체가 됩니다. 참고하는 store가 여러 개라면 <code>derived([a, ...b], ...)</code>로 배열이 됩니다.</li>
<li>두 번째 파라미터는 새로운 store의 값을 리턴하는 콜백 함수입니다. 콜백 함수의 파라미터는 참고하는 store입니다. 콜백 함수의 마지막 파라미터는 <code>set</code> 함수입니다. <code>derived([a, ...b], ([$a, ...$b], set) => ...)</code>와 같은 형태입니다.</li>
<li>세 번째 파라미터는 새로운 store의 초깃값입니다.</li>
</ul>
<p>자세한 API 레퍼런스는 <a href="https://svelte.dev/docs#derived">https://svelte.dev/docs#derived</a>를 참고 바랍니다.</p>

<p>커스텀 한 store을 만드는 것은 어렵지 않습니다. <code>subscribe</code>가 구현되어 있으면 모두 store이기 때문에 <code>subscribe</code> 함수를 가지는 객체를 만들면 됩니다. <code>stores.js</code>를 살펴보겠습니다. <code>count</code>는 <code>subscribe</code>, <code>increment</code>, <code>decrement</code>, <code>reset</code> 함수를 가지는 store입니다.</p>
<ul>
<li><code>increment</code>: <code>update(n => n + 1)</code>로 관찰하는 값을 1 증가시킵니다.</li>
<li><code>decrement</code>: <code>update(n => n - 1)</code>로 관찰하는 값을 1 감소시킵니다.</li>
<li><code>reset</code>: <code>set(0)</code>로 관찰하는 값을 0으로 초기화 시킵니다.</li>
</ul>

<li><code>App.svelte</code>는 2가지 방법을 사용하여 <code>name</code> store의 값을 변경시킵니다. <code>name</code> store의 자동 구독 방법을 사용하면 일반 변수처럼 사용할 수 있습니다.
<ul>
<li><code>&#x3C;input></code>: <code>&#x3C;input bind:value={$name}></code>로 <code>&#x3C;input></code> 태그의 <code>value</code> 속성에 <code>$name</code>을 바인딩 하였습니다. <code>&#x3C;input></code> 태그의 입력 값이 들어오면 <code>$name</code>에 반영됩니다.</li>
<li><code>&#x3C;button></code>: <code>&#x3C;button></code> 태그에 <code>click</code>이벤트가 발생하면 <code>$name</code>에 <code>!</code> 문자를 추가합니다.</li>
</ul>
</li>
