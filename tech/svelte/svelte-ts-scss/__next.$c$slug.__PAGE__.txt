<h4 id="소스코드에서-scss-파일-import하기">소스코드에서 SCSS 파일 <code>import</code>하기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#소스코드에서-scss-파일-import하기"><span class="anchor-icon">#</span></a></h4>
<p><code>sass</code> 패키지를 다운로드 한 후 <code>svelte-preprocess</code>를 사용하면 Svelte 컴포넌트에서 <code>&#x3C;style lang="scss"></code>를 사용해서 SCSS를 사용할 수 있지만, <code>.scss</code> 파일을 <code>import</code>하여 스타일을 적용할 수는 없습니다. 소스코드에서 SCSS 파일을 <code>import</code>할 수 있도록 설정해 보도록 하겠습니다. <code>rollup.config.js</code>를 아래와 같이 수정합니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">// rollup.config.js</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">//...</span></span>

<span class="line"></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">export</span><span style="color:#A0111F;--shiki-dark:#FF9492"> default</span><span style="color:#702C00;--shiki-dark:#FFB757"> {</span></span>

<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">    scss</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">({</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">      output: </span><span style="color:#032563;--shiki-dark:#ADDCFF">'public/build/assets.css'</span></span>

<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">    //...</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  ]</span></span>

<h4 id="prependdata-설정"><code>prependData</code> 설정<a class="anchor after" aria-hidden="true" tabindex="-1" href="#prependdata-설정"><span class="anchor-icon">#</span></a></h4>
<p>SCSS 파일에 정의된 스타일이나 변수들을 컴포넌트의 <code>&#x3C;style></code>에서 <code>@import</code> 해서 사용해야 할 때, <code>prependData</code>를 사용하면 컴포넌트의 <code>&#x3C;style></code>에서 <code>@import</code>를 사용하지 않고 SCSS 변수를 가져와 사용할 수 있습니다. 아래와 같이 <code>svelte.config.js</code> 파일에서 <code>prependData</code>를 정의할 수 있습니다.</p>
