<h4 id="실행-화면-6">실행 화면<a class="anchor after" aria-hidden="true" tabindex="-1" href="#실행-화면-6"><span class="anchor-icon">#</span></a></h4>
<p><img src="/assets/img/posts/svelte/crossfade_transition.gif" alt="crossfade 트랜지션" loading="lazy" decoding="async" width="726" height="289" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/crossfade_transition-opt-640.WEBP 640w, /assets/img/posts/svelte/nextImageExportOptimizer/crossfade_transition-opt-1080.WEBP 1080w" sizes="(max-width: 640px) 100vw, 1000px"></p>
<h4 id="사용방법">사용방법<a class="anchor after" aria-hidden="true" tabindex="-1" href="#사용방법"><span class="anchor-icon">#</span></a></h4>
<p><code>crossfade</code> 트랜지션의 사용방법은 다른 트랜지션을 사용하는 방법과 조금 다릅니다. 사용방법을 순서대로 살펴보겠습니다.</p>
<ul>
<li><code>import { crossfade } from 'svelte/transition';</code>로 <code>crossfade</code> 함수를 가져옵니다.</li>
<li><code>const [send, receive] = crossfade(params)</code>로 함수를 호출합니다.</li>
<li><code>crossfade</code> 함수의 파라미터로 <code>duration</code>, <code>delay</code>, <code>fallback</code> 속성을 포함한 객체를 전달합니다.
<ul>
<li><code>duration</code> (number | function, default: <code>d => Math.sqrt(d) * 30</code>): 단위는 ms로 트랜지션 지속시간입니다. 함수일 경우 <code>d</code>는 거리입니다.</li>
<li><code>delay</code> (number, default: 0): 단위는 ms로 설정한 시간 후에 트랜지션이 시작됩니다.</li>
<li><code>easing</code> (function, default: cubicOut): easing 함수입니다. <a href="https://svelte.dev/docs#svelte_easing">https://svelte.dev/docs#svelte_easing</a> 참고 바랍니다.</li>
<li><code>fallback</code> (function): 이동할 대상이 없는 경우 실행되는 트랜지션을 정의합니다.</li>
</ul>
</li>
<li><code>crossfade</code> 함수의 리턴 값은 <code>[send, receive]</code> 형태의 배열입니다.
<ul>
<li><code>send</code>: 내보내는 트랜지션입니다. <code>out:send="{{key: todo.id}}"</code> 형태로 사용해야 합니다. 유니크한 key를 가진 객체를 파라미터로 전달해야 합니다.</li>
<li><code>receive</code> 받는 트랜지션입니다. <code>in:receive="{{key: todo.id}}"</code> 형태로 사용해야 합니다. <code>send</code> 트랜지션과 동일하게 유니크한 key를 가진 객체를 파라미터로 전달해야 합니다.</li>
</ul>
</li>
</ul>
<p>받는 대상, 보내는 대상이 없는 경우 <code>fallback</code>에 정의한 트랜지션이 동작하게 되는데, <code>fallback</code>에 트랜지션을 정의하는 방법은 <a href="/tech/svelte/transition/#%EC%BB%A4%EC%8A%A4%ED%85%80-%ED%8A%B8%EB%9E%9C%EC%A7%80%EC%85%98-%EB%A7%8C%EB%93%A4%EA%B8%B0">/tech/svelte/transition/#커스텀-트랜지션-만들기</a>에서 자세히 이야기하도록 하고 지금은 넘어가도록 하겠습니다.</p>
<p><code>send</code>와 <code>receive</code> 트랜지션을 사용할 때, 받을 때 사용한 <code>in</code>과 내보낼 때 사용한 <code>out</code>에 대해 살펴보겠습니다.</p>
<h2 id="트랜지션-inout">트랜지션 In/Out<a class="anchor after" aria-hidden="true" tabindex="-1" href="#트랜지션-inout"><span class="anchor-icon">#</span></a></h2>
<p>트랜지션을 사용할 때, <code>transition</code> 디렉티브 대신에 <code>in</code>, <code>out</code> 디렉티브를 사용할 수 있습니다. <code>in</code>, <code>out</code> 디렉티브를 사용하면 요소가 추가, 제거될 때 각각 다른 트랜지션을 설정할 수 있습니다. <code>in</code>, <code>out</code> 트랜지션을 사용하는 예제를 살펴보도록 하겠습니다.</p>

<h2 id="커스텀-트랜지션-만들기">커스텀 트랜지션 만들기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#커스텀-트랜지션-만들기"><span class="anchor-icon">#</span></a></h2>
<p>Svelte에서 제공하는 7가지 트랜지션 외의 트랜지션이 필요할 때, 원하는 트랜지션을 만들 수 있습니다. CSS와 자바스크립트를 사용하여 트랜지션을 만드는 방법을 이야기하도록 하겠습니다.</p>
<p>위에서 이야기 했던 <code>crossfade</code> 트랜지션 함수의 <code>fallback</code>도 커스텀 트랜지션과 동일한 방법으로 정의하면 됩니다.</p>

<h4 id="파라미터-6">파라미터<a class="anchor after" aria-hidden="true" tabindex="-1" href="#파라미터-6"><span class="anchor-icon">#</span></a></h4>
<p>트랜지션 함수는 2개의 파라미터를 가집니다.</p>
<ul>
<li><code>node</code>: 첫 번째 파라미터는 트랜지션이 적용되는 HTML 요소입니다.</li>
<li><code>params</code>: 두 번째 파라미터는 <code>transition:fade={params}</code>에 <code>params</code>로 전달될 값입니다. 두 번째 파라미터에는 모든 형태의 값을 전달할 수 있습니다.</li>
</ul>
<h4 id="리턴-값">리턴 값<a class="anchor after" aria-hidden="true" tabindex="-1" href="#리턴-값"><span class="anchor-icon">#</span></a></h4>
<p>트랜지션 함수는 객체를 리턴해야 합니다. 리턴하는 객체는 아래의 속성을 가져야 합니다.</p>
<ul>
<li><code>delay</code>: 단위는 ms로 설정한 시간이 지난 후에 트랜지션을 시작합니다.</li>
<li><code>duration</code>: 단위는 ms로 설정한 시간 동안 트랜지션 됩니다.</li>
<li><code>easing</code>: easing 함수입니다. <a href="https://svelte.dev/docs#svelte_easing">https://svelte.dev/docs#svelte_easing</a> 참고 바랍니다.</li>
<li><code>css</code>: <code>(t, u) => string</code> 함수입니다. <code>t</code>는 0 ~ 1 사이의 값이고, <code>u</code>는 <code>u === 1 - t</code>입니다. 요소가 추가될 때 <code>t</code>는 0에서 1로 증가하고, 요소가 제거될 때 <code>t</code>는 1에서 0으로 감소합니다. <code>t</code>(혹은 <code>u</code>)의 변화에 따른 CSS 문자열을 리턴해야 합니다.</li>
<li><code>tick</code>: <code>(t, u) => void</code> 함수입니다. 매 tick마다 호출되는 콜백 함수입니다.</li>
</ul>
<p><code>css</code>와 <code>tick</code> 속성을 사용하면 커스텀 한 트랜지션을 만들 수 있습니다. <code>tick</code> 속성은 매 <code>tick</code>마다 호출되는 콜백 함수이기 때문에 <code>tick</code>을 사용하여 만들어진 트랜지션은 매끄러운 애니메이션이 동작하지 않을 수 있습니다. 커스텀 한 트랜지션을 만들 때는 <code>css</code> 속성을 사용하여 만드는 것을 권장합니다.</p>
<h3 id="css로-트랜지션-만들기">CSS로 트랜지션 만들기<a class="anchor after" aria-hidden="true" tabindex="-1" href="#css로-트랜지션-만들기"><span class="anchor-icon">#</span></a></h3>

<h2 id="트랜지션-이벤트">트랜지션 이벤트<a class="anchor after" aria-hidden="true" tabindex="-1" href="#트랜지션-이벤트"><span class="anchor-icon">#</span></a></h2>
<p>Svelte는 트랜지션이 언제 시작되고 끝이 나는지 알려주는 트랜지션 이벤트를 제공합니다. 사용하는 방법은 다른 DOM 이벤트와 동일합니다. 예제 코드를 살펴보도록 하겠습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  import</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> { fly } </span><span style="color:#A0111F;--shiki-dark:#FF9492">from</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'svelte/transition'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> visible </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#023B95;--shiki-dark:#91CBFF"> true</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> status </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'waiting...'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>

<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">>status: {status}&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">input</span><span style="color:#023B95;--shiki-dark:#91CBFF"> type</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"checkbox"</span><span style="color:#023B95;--shiki-dark:#91CBFF"> bind:checked</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">{visible}</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  visible</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{#if visible}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    transition:fly</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"{{ y: 200, duration: 2000 }}"</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    on:introstart</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"{() => status = 'intro started'}"</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    on:outrostart</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"{() => status = 'outro started'}"</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    on:introend</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"{() => status = 'intro ended'}"</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    on:outroend</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"{() => status = 'outro ended'}"</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  ></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    Flies in and out</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">p</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{/if}</span></span></code></pre>
<ul>
<li><code>introstart</code>: 요소가 추가되는 트랜지션의 시작 이벤트입니다.</li>
<li><code>outrostart</code>: 요소가 제거되는 트랜지션의 시작 이벤트입니다.</li>
<li><code>introend</code>: 요소가 추가되는 트랜지션의 종료 이벤트입니다.</li>
<li><code>outroend</code>: 요소가 제거되는 트랜지션의 종료 이벤트입니다.</li>
</ul>
<h2 id="트랜지션의-수식어">트랜지션의 수식어<a class="anchor after" aria-hidden="true" tabindex="-1" href="#트랜지션의-수식어"><span class="anchor-icon">#</span></a></h2>
<p>트랜지션을 사용한 블록에서만 요소가 추가, 제거 될 때 트랜지션이 적용될 수 있게 하는 수식어를 제공합니다.</p>
<h3 id="local"><code>local</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#local"><span class="anchor-icon">#</span></a></h3>
<p><code>local</code> 수식어를 사용하면 상위 블록에 요소가 추가될 경우에만 트랜지션이 동작합니다. 말로는 이해하기 어려우니 예제를 하나 살펴보도록 하겠습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="html"><code><span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  import</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> { slide } </span><span style="color:#A0111F;--shiki-dark:#FF9492">from</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'svelte/transition'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> showItems </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#023B95;--shiki-dark:#91CBFF"> true</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> i </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#023B95;--shiki-dark:#91CBFF"> 5</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">  let</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> items </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> [</span><span style="color:#032563;--shiki-dark:#ADDCFF">'one'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'two'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'three'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'four'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'five'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'six'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'seven'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'eight'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'nine'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="color:#032563;--shiki-dark:#ADDCFF">'ten'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">];</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">script</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#024C1A;--shiki-dark:#72F088">  div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#023B95;--shiki-dark:#91CBFF">    padding</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#023B95;--shiki-dark:#91CBFF">0.5</span><span style="color:#A0111F;--shiki-dark:#FF9492">em</span><span style="color:#023B95;--shiki-dark:#91CBFF"> 0</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">;</span></span>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">style</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">input</span><span style="color:#023B95;--shiki-dark:#91CBFF"> type</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"checkbox"</span><span style="color:#023B95;--shiki-dark:#91CBFF"> bind:checked</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">{showItems}</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  show list</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">input</span><span style="color:#023B95;--shiki-dark:#91CBFF"> type</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">"range"</span><span style="color:#023B95;--shiki-dark:#91CBFF"> bind:value</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">{i}</span><span style="color:#023B95;--shiki-dark:#91CBFF"> max</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">=</span><span style="color:#032563;--shiki-dark:#ADDCFF">10</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">&#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">label</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{#if showItems}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  {#each items.slice(0, i) as item}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    &#x3C;</span><span style="color:#024C1A;--shiki-dark:#72F088">div</span><span style="color:#023B95;--shiki-dark:#91CBFF"> transition:slide|local</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">      {item}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    &#x3C;/</span><span style="color:#024C1A;--shiki-dark:#72F088">div</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">></span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  {/each}</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">{/if}</span></span></code></pre>
<p>위의 코드와 같이 <code>transition:slide|local</code> 사용하여 <code>local</code> 수식어를 사용할 수 있습니다. 위의 코드는 <code>local</code> 수식어를 사용했기 때문에 상위 블록에 요소인 <code>{#each }</code> 블록에 요소가 추가될 때에만 트랜지션이 동작합니다. <code>local</code> 수식어 사용한 경우와 사용하지 않은 경우를 비교해 보겠습니다.</p>













<table><thead><tr><th align="center"><code>local</code> 미사용</th><th align="center"><code>local</code> 사용</th></tr></thead><tbody><tr><td align="center"><img src="/assets/img/posts/svelte/not_use_local.gif" alt="local 미사용" loading="lazy" decoding="async" width="205" height="320" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/not_use_local-opt-640.WEBP 640w" sizes="(max-width: 640px) 100vw, 1000px"></td><td align="center"><img src="/assets/img/posts/svelte/use_local.gif" alt="local 사용" loading="lazy" decoding="async" width="205" height="320" srcset="/assets/img/posts/svelte/nextImageExportOptimizer/use_local-opt-640.WEBP 640w" sizes="(max-width: 640px) 100vw, 1000px"></td></tr></tbody></table>
<p>위의 2개의 그림을 비교해서 보면,</p>
<ul>
<li><code>local</code> 수식어 미사용: 전체 리스트가 나타날 때와 목록이 추가될 때 트랜지션이 동작하는 것을 볼 수 있습니다.</li>
<li><code>local</code> 수식어 사용: 전체 리스트가 나타날 때는 트랜지션이 동작하지 않지만 목록이 추가될 때는 트랜지션이 동작하는 것을 볼 수 있습니다.</li>
</ul>
