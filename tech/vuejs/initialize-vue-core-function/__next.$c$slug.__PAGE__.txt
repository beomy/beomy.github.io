<li><code>Vue.prototype.__patch__ = inBrowser ? patch : noop</code>은 웹페이지를 업데이트 하는 역할을 합니다. 즉, DOM을 조작하는 역할을 합니다. <a href="/tech/vuejs/view-render-patch/">9. View Render - Patch</a>에서 자세히 다루어 보도록 하겠습니다.</li>
<li><code>Vue.prototype.$mount</code>는 <code>mountComponent</code>를 호출하는 역할을 합니다. <code>$mount</code>는 이전 포스트에서 몇가지 검증을 추가하여 캡슐화 된다고 이야기 했습니다. 이 파일에서 한번더 캡슐화 되어 2번 캡슐화 됩니다. <code>mountComponent</code> 함수도 view를 업데이트 하는 핵심 함수입니다. <a href="/tech/vuejs/view-render-patch/">9. View Render - Patch</a>에서 자세히 다루어 보도록 하겠습니다.</li>
</ol>
<p><code>import Vue from 'core/index'</code>에서 Vue 파일라고 정의 되어 있는 <code>src/core/index.js</code> 파일을 따라가 보도록 하겠습니다.</p>

<h2 id="vue의-layer">Vue의 Layer<a class="anchor after" aria-hidden="true" tabindex="-1" href="#vue의-layer"><span class="anchor-icon">#</span></a></h2>
<p>Vue는 큰 프로젝트입니다. 그래서 Vue는 많은 Layer와 part들로 나누어져 있습니다. Vue는 크게 4가지로 Layer로 구성됩니다.</p>
<p><img src="/assets/img/posts/vuejs/vue_layer.png" alt="Vue layer" loading="lazy" decoding="async" width="720" height="250" srcset="/assets/img/posts/vuejs/nextImageExportOptimizer/vue_layer-opt-640.WEBP 640w, /assets/img/posts/vuejs/nextImageExportOptimizer/vue_layer-opt-1080.WEBP 1080w" sizes="(max-width: 640px) 100vw, 1000px"></p>
<ul>
<li><strong>Core Layer</strong>: Vue 코어 함수입니다. <code>this._init()</code>을 호출합니다. <code>src/core/instance/index.js</code>에서 살펴 볼 수 있습니다.</li>
<li><strong>Mixins Layer</strong>: init, state, events, lifecycle, render, 5개의 mixin 함수를 Vue 코어에 추가 합니다. <code>src/core/instance/index.js</code>에서 살펴 볼 수 있습니다.</li>
<li><strong>Platform Layer</strong>: 몇가지 동작들을 Vue 코어에 추가합니다. <code>Vue.prototype.__patch__</code>와 <code>Vue.prototype.$mount</code>를 추가합니다. <code>src/platforms/web/runtime/index.js</code>에서 살펴 볼 수 있습니다.</li>
<li><strong>Entry Layer</strong>: config와 캡슐화 된 $mount의 가장 바깥쪽 <code>$mount</code>를 Vue 코어에 추가합니다. <code>src/platforms/web/entry-runtime-with-compiler.js</code>에서 살펴 볼 수 있습니다.</li>
</ul>
<p>이렇게 여러개의 layer로 구성한다면 몇가지 장점이 있습니다.</p>
<ol>
<li>관심사를 분리 할 수 있습니다. 각각의 layer는 서로 다른 일들을 하게 됩니다.</li>
<li>캡슐화 할 수 있습니다. 각각의 layer는 각자의 일에만 집중하면 됩니다.</li>
<li>재사용 할 수 있습니다. 코어에 가까울수록 일반적(generic)을 코드가 됩니다. 이로 인해 다른 플랫폼에 쉽게 호환이 되고, 다른 환경에서 쉽게 구축할 수 있습니다.</li>
</ol>
<h2 id="요약">요약<a class="anchor after" aria-hidden="true" tabindex="-1" href="#요약"><span class="anchor-icon">#</span></a></h2>
<p><code>src/platforms/web/runtime/index.js</code>를 시작으로 <code>src/core/instance/index.js</code>에 도달하여 Vue 코어 함수를 찾았습니다. <code>src/core/instance/index.js</code> 파일은 Vue 함수를 <code>export</code> 하게 되는데, <code>export</code>되는 Vue 함수는 5개의 mixin가 추가된 Vue 함수입니다. Vue 함수는 <code>this_init</code> 함수를 호출하여 초기화 합니다.</p>
