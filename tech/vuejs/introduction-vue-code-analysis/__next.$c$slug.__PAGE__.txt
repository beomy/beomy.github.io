<h4 id="--main-module-unpkg-jsdelivr">- <code>main</code>, <code>module</code>, <code>unpkg</code>, <code>jsdelivr</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#--main-module-unpkg-jsdelivr"><span class="anchor-icon">#</span></a></h4>
<p><code>main</code>, <code>module</code>, <code>unpkg</code>, <code>jsdelivr</code> 옵션에 <code>dist/</code> 값들이 있는 것을 확인 할 수 있습니다. <code>dist</code> 디렉토리와 하위에 있는 파일들은 빌드을 하면 자동으로 생성되는 파일들입니다. 즉 이 옵션들이 가르키는 값들은 빌드되어 생성된 결과물입니다.</p>
<h4 id="--typings">- <code>typings</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#--typings"><span class="anchor-icon">#</span></a></h4>
<p><code>typings</code>는 TypeScript를 정의한 파일을 나타내는 옵션입니다. Vue 코드는 TypeScript로 작성되어 있기 때문에, TypeScript를 알고 계신다면 더 쉽게 코드를 분석해 나갈 수 있습니다.</p>
<p><code>types/index.d.ts</code> 파일에 정의된 type들을 볼 수 있습니다.</p>
<h4 id="--files">- <code>files</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#--files"><span class="anchor-icon">#</span></a></h4>
<p><code>files</code> 옵션은 npm 옵션 중 하나로, 패키지가 의존성으로 설치될 때 같이 포함될 파일들의 배열입니다. <code>files</code> 옵션에는 3개의 경로들이 지정되어 있습니다. 포함된 경로 중에 <code>src</code>가 있는데, 이 디렉토리에 Vue 코드들이 모여 있습니다.</p>
<h4 id="--sideeffects">- <code>sideEffects</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#--sideeffects"><span class="anchor-icon">#</span></a></h4>
<p><code>sideEffects</code> 옵션은 <a href="https://webpack.js.org/configuration/optimization/#optimizationsideeffects">webpack 옵션</a> 중 하나 입니다. 자세한 설명은 링크를 참고 부탁드립니다.</p>
<h4 id="--scripts">- <code>scripts</code><a class="anchor after" aria-hidden="true" tabindex="-1" href="#--scripts"><span class="anchor-icon">#</span></a></h4>
<p><code>scripts</code> 옵션은 node.js 명령 스크립트를 정의하는 옵션입니다. <code>scripts</code> 옵션의 <code>dev</code>를 살펴 보도록 하겠습니다.</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="bash"><code><span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">rollup</span><span style="color:#023B95;--shiki-dark:#91CBFF"> -w</span><span style="color:#023B95;--shiki-dark:#91CBFF"> -c</span><span style="color:#032563;--shiki-dark:#ADDCFF"> scripts/config.js</span><span style="color:#023B95;--shiki-dark:#91CBFF"> --environment</span><span style="color:#032563;--shiki-dark:#ADDCFF"> TARGET:web-full-dev</span></span></code></pre>
<p>이렇게 정의 되어 있습니다. <code>scripts/config.js</code> 파일에 <code>web-full-dev</code>를 찾아 보도록 하겠습니다.</p>

<p><code>entry-runtime-with-compiler.js</code>의 첫번 째 줄에 정의 된 <code>/* @flow */</code>는 type checker 입니다. <a href="https://flow.org/en/">flow</a>는 <code>package.json</code>에서 살펴 본 <code>typings</code>의 타입들을 체크 하는 역할을 합니다.</p>
<p><code>entry-runtime-with-compiler.js</code>가 수행하는 일들은 아래와 같습니다,</p>
<ul>
<li><code>config</code>를 import 합니다.</li>
<li>유틸 함수들을 import 합니다.</li>
<li><code>Vue</code>를 import 합니다.</li>
<li><code>idToTemplate</code>를 정의합니다.</li>
<li><code>getOuterHTML</code>를 정의합니다.</li>
<li><code>idTotemplate</code>와 <code>getOuterHTML</code>를 사용하여 <code>Vue.prototype.$mount</code>를 정의합니다.</li>
<li><code>Vue.compile</code>를 정의합니다</li>
</ul>
<p>2가지 내용을 집중해야 합니다.</p>
<ol>
<li>이 코드는 Vue 코어 코드가 아닙니다. <code>entry-runtime-with-compiler.js</code> 이라는 파일 이름에서 알 수 있듯이 단순 entry 역할(코어 코드를 감싸는 역할)을 할 뿐입니다. 코어 코드는 다음 포스트에서 자세히 이야기 하도록 하겠습니다.</li>
<li><code>$mount</code>를 따로 저장하고, 새로운 <code>$mount</code>를 정의하여 몇가지 검증을 한 후 저장한 <code>$mount</code>를 호출합니다.(캡슐화하는 부분입니다.) 즉, 실제 <code>$mount</code>를 호출하기 전에 몇가지 검증을 추가하는 코드입니다.</li>
</ol>
<h2 id="요약">요약<a class="anchor after" aria-hidden="true" tabindex="-1" href="#요약"><span class="anchor-icon">#</span></a></h2>
<ol>
<li><code>package.json</code>의 <code>scripts</code>의 <code>dev</code>의 값인 <code>rollup -w -c scripts/config.js --environment TARGET:web-full-dev</code>를 시작으로 코드 리딩을 시작합니다.</li>
<li><code>scripts/config.js</code>파일을 거쳐 <code>src/platforms/web/entry-runtime-with-compiler.js</code> 파일에 도착하였습니다.</li>
</ol>
<p><code>src/platforms/web/entry-runtime-with-compiler.js</code>는 Vue 코어 코드가 아닌 entry 역할만 하는 코드입니다.</p>
<h2 id="다음으로-볼-것">다음으로 볼 것<a class="anchor after" aria-hidden="true" tabindex="-1" href="#다음으로-볼-것"><span class="anchor-icon">#</span></a></h2>
