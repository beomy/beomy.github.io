<p><code>observe</code> 함수는 존재하는 observer를 리턴하거나, observer를 생성(<code>new Observer(value)</code>)하여 리턴합니다. 객체일 때만 observer 타입을 리턴 합니다. 원시 값(Number, String 등..)은 void 값을 리턴합니다.</p>
<p><code>value</code>가 root data 일 경우 <code>ob.vmCount++</code>로 vmCount를 증가시켜 <code>value</code>를 root data로 하는 컴포넌트 갯수를 체크합니다.</p>

<p><code>this.value</code>, <code>this.dep</code>, <code>this.vmCount</code>를 초기화와 <code>__ob__</code> 프로퍼티를 정의합니다.</p>
<p><code>value</code>가 배열 일 경우, array 메소드(<code>push</code>, <code>pop</code>과 같은..)를 중간에 가로체 재정의 합니다. 이유는 Vue가 array 메소드를 호출했을때 알아차리기 위해서 입니다. 그 후 <code>observeArray</code> 함수를 호출합니다. <code>observeArray</code> 함수는 반복문을 통해 <code>observe</code> 함수를 실행하여 각 요소들을 반응형 프로퍼티로 만들어 줍니다.</p>
<p>배열이 아닌 경우 <code>this.walk</code> 함수를 실행합니다. 이 함수는 객체에 각 요소마다 <code>defineReactive</code>를 호출하여 각 요소를 반응형 프로퍼티로 만들어줍니다.</p>
<p><code>defineReactive</code> 함수에서 시작해서 <code>Observer</code> 클래스까지 코드 호출 순서를 보면,</p>
<ol>
<li><code>defineReactive()</code> 호출</li>
<li><code>observe()</code> 호출</li>
<li><code>new Observe(value)</code> 호출</li>
<li><code>this.walk()</code> 호출</li>
<li><code>defineReactive()</code> 호출</li>
</ol>
<p><code>defineReactive</code> 함수 호출로 시작하여 <code>defineReactive</code> 함수를 호출합니다. 이렇게 재귀적으로 <code>defineReactive</code> 함수를 호출하여 모든 하위 요소들을 반응형 프로퍼티로 변환하게 됩니다.</p>
<p>이렇게 객체의 모든 하위 요소를 반응형 프로퍼티로 변환하는 이유는,</p>
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">data</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: {</span></span>
<span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">  name</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">'foo'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">,</span></span>

<span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">    mom</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">'foomom'</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">,</span></span>
<span class="line"><span style="color:#702C00;--shiki-dark:#FFB757">    dad</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="color:#032563;--shiki-dark:#ADDCFF">'foodad'</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<p>위의 코드와 같이 <code>data</code>라는 객체가 있을 때, <code>data.name</code>의 값이나 <code>data.parents.mom</code>의 값이 변경 되었을 때, <code>data</code>의 setter 함수는 호출 되지 습니다. setter 함수가 호출되지 않으면 <code>notify</code>가 호출되지 않아 view가 업데이트 되지 않습니다.</p>
<p>재귀적으로 <code>defineReactive</code> 함수를 호출하면, 모든 하위 요소를 반응형 프로퍼티로 변환되어 <code>data.name</code>이나 <code>data.parents.mom</code>의 값이 변경 되어도 자동으로 view를 업데이트 할 수 있게 됩니다.</p>

<h4 id="notify-함수"><code>notify</code> 함수<a class="anchor after" aria-hidden="true" tabindex="-1" href="#notify-함수"><span class="anchor-icon">#</span></a></h4>

<h2 id="watcher">Watcher<a class="anchor after" aria-hidden="true" tabindex="-1" href="#watcher"><span class="anchor-icon">#</span></a></h2>

<h3 id="watcher-클래스"><code>Watcher</code> 클래스<a class="anchor after" aria-hidden="true" tabindex="-1" href="#watcher-클래스"><span class="anchor-icon">#</span></a></h3>
<p><code>Watcher</code> 클래스의 코드는 좀 양이 많습니다. 클래스 상단의 주석을 통해 <code>Watcher</code> 클래스의 역할을 살펴볼 수 있습니다.</p>
<blockquote>
<p>A watcher parses an expression, collects dependencies, and fires callback when the expression value changes. This is used for both the $watch() api and directives.</p>
</blockquote>
<p><code>Watcher</code> 클래스는 expression(생성자를 통해 <code>expOrFn</code> 이름으로 전달 받습니다.)을 파싱하고, 종속성을 모으고, expression 값이 변경 될 때, 콜백함수를 실행합니다.</p>
<p><code>$watch()</code>(<a href="/tech/vuejs/initialize-mixin-layer/#statemixin-%ED%95%A8%EC%88%98">3. Initialize - Mixin Layer</a>에서 살펴본 <code>stateMixin</code> 함수에서 정의합니다.)와 <code>initComputed</code>(<a href="/tech/vuejs/initialize-_init-function/#initcomputed-%ED%95%A8%EC%88%98">4. Initialize - _init 함수</a>에서 살펴보았습니다.)에서 <code>Watcher</code> 인스턴스를 생성합니다.</p>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<p>위의 코드와 같이 Vue 옵션을 정의했다고 가정합시다.</p>
<ol>
<li><code>Vue</code> 함수</li>
<li><code>this._init()</code> 실행 (<code>initMixin</code> 함수에 <code>Vue.prototype._init</code> 함수임)</li>
<li><code>initState(vm)</code> 실행</li>
<li><code>initState</code> 함수에서 <code>initData(vm)</code> 실행</li>
<li><code>proxy(vm, '_data', key)</code> 실행</li>
<li><code>observe(data, true /* asRootData */)</code> 실행
위의 순서로 <code>data</code> 는 반응형 프로퍼티로 변환됩니다. <code>proxy</code> 함수로 인해 <code>this.name</code>은 <code>this._data['name']</code>으로 프록시 됩니다.</li>
</ol>
<p>이제 본격적으로 <code>Watcher</code> 클래스의 동작 순서를 이야기 해 보겠습니다.</p>
<ol>
<li><code>Vue</code> 함수 -> <code>this._init</code> -> <code>initState</code> -> <code>initComputed</code> -> <code>new Watcher(...)</code> 순서로 <code>Watcher</code> 인스턴스가 생성됩니다.</li>
<li>생성자 함수에서 <code>this.get()</code>를 호출합니다.</li>
<li><code>get</code> 함수에서 <code>pushTarget(this)</code>를 호출하여 <code>Dep.target</code>를 현재 watcher로 변경합니다.</li>
<li><code>get</code> 함수에서 <code>this.getter.call(vm, vm)</code>를 호출합니다. <code>this.getter</code>는 <code>initComputed</code> 함수에서 <code>Watcher</code> 인스턴스를 생성 할 때 전달 받은 <code>getter</code> 입니다. 즉, <code>this.getter</code>는 <code>computed</code> 속성에 정의된 함수입니다.
<pre class="shiki shiki-themes github-light-high-contrast github-dark-high-contrast" style="background-color:#ffffff;--shiki-dark-bg:#0a0c10;color:#0e1116;--shiki-dark:#f0f3f6" tabindex="0" data-language="js"><code><span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> userDef</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> computed[key]</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">const</span><span style="color:#023B95;--shiki-dark:#91CBFF"> getter</span><span style="color:#A0111F;--shiki-dark:#FF9492"> =</span><span style="color:#A0111F;--shiki-dark:#FF9492"> typeof</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> userDef </span><span style="color:#A0111F;--shiki-dark:#FF9492">===</span><span style="color:#032563;--shiki-dark:#ADDCFF"> 'function'</span><span style="color:#A0111F;--shiki-dark:#FF9492"> ?</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> userDef </span><span style="color:#A0111F;--shiki-dark:#FF9492">:</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> userDef.get</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">...</span></span>
<span class="line"><span style="color:#A0111F;--shiki-dark:#FF9492">if</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> (</span><span style="color:#A0111F;--shiki-dark:#FF9492">!</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">isSSR) {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">  // create internal watcher for the computed property.</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  watchers[key] </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#A0111F;--shiki-dark:#FF9492"> new</span><span style="color:#622CBC;--shiki-dark:#DBB7FF"> Watcher</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    vm,</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    getter </span><span style="color:#A0111F;--shiki-dark:#FF9492">||</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> noop,</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    noop,</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    computedWatcherOptions</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">  )</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
위의 코드는 <code>initComputed</code> 함수에서 <code>Watcher</code> 인스턴스를 생성하는 코드입니다.</li>
<li><code>this.getter.call(vm, vm)</code>는 결국 <code>return this.name + 'new!'</code>를 호출한 것과 같습니다.</li>
<li><code>this.name</code>은 <code>this._data['name']</code>이 프록시 된 값입니다. 반응형 프로퍼티인 <code>this._data['name']</code>의 getter(<code>defineReactive</code> 함수의 get 함수)가 실행됩니다.</li>
<li><code>defineReactive</code> 함수에서 정의한 get 함수에서 <code>dep.depend()</code>를 호출합니다.</li>
<li><code>Dep</code> 클래스의 <code>depend</code> 함수에서 <code>Dep.target.addDep(this)</code>를 호출합니다. 여기서 <code>this</code>는 <code>defineReactive</code> 함수에서 정의 한 <code>dep</code>(<code>const dep = new Dep()</code>)입니다. <code>defineReactive</code>를 호출한 주체는 <code>_data</code>이기 때문에, <code>dep</code>은 <code>_data</code>의 <code>dep</code>입니다.</li>
<li><code>defineReactive</code> 함수에서 정의한 get 함수에서 <code>childOb.dep.depend()</code>를 호출합니다.</li>
<li><code>Dep.target.addDep(this)</code>를 호출하는데, <code>this</code>는 <code>childOb.__ob__.dep</code>입니다.</li>
<li><code>Watcher</code> 클래스의 <code>addDep</code> 함수에서 <code>this.newDepIds</code>와 <code>this.newDeps</code>에 각각 <code>dep.id</code>와 <code>dep</code>을 저장합니다.</li>
<li><code>Watcher</code> 클래스의 <code>addDep</code> 함수에서 <code>this.depIds</code>의 기본 값은 빈 배열(<code>[]</code>)이기 때문에 <code>dep.addSub(this)</code>를 호출하게 됩니다.</li>
<li><code>Dep</code> 클래스의 <code>addSub</code>는 <code>this.subs</code>에 현재 Watcher를 등록하는 역할을 합니다.</li>
<li>6 ~ 13번을 거쳐 <code>Watcher</code> 클래스의 <code>get</code> 함수의 <code>value</code>에 값이 세팅됩니다.</li>
<li><code>Watcher</code> 클래스의 <code>get</code> 함수에서 <code>traverse(value)</code>를 호출합니다.</li>
<li><code>Watcher</code> 클래스의 <code>get</code> 함수에서 <code>popTarget()</code>를 호출합니다.</li>
<li><code>Watcher</code> 클래스의 <code>get</code> 함수에서 <code>this.cleanupDeps()</code>를 호출합니다. <code>cleanupDeps</code> 함수는 종속성을 업데이트 하는 역할을 합니다.</li>
</ol>
<p>위의 과정을 거치면서 Watcher는 종속성(<code>Dep</code>)을 알게 되고, <code>Dep</code>는 구독자(subscriber)들을 알게 됩니다. 쉽게 말에 위의 과정을 통해 <code>Watcher</code>와 <code>Dep</code>과 <code>Observer</code>가 관계를 형성합니다. 이 관계를 통해 Vue는 반응형으로 동작하게 됩니다.</p>
<p>반응형 프로퍼티들이 새로운 값으로 변경되면, <code>Dep</code>의 <code>notify</code> 함수가 호출되어 구독자들의 <code>get</code> 함수가 호출되고, 값과 관계(<code>Watcher</code>와 <code>Dep</code>과 <code>Observer</code>의 관계)들이 업데이트 됩니다.</p>
