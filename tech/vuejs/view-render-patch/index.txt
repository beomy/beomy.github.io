<p>위의 코드의 주석번호(<code>// 1</code> 등..)와 밑의 설명의 번호를 매칭하면서 보시길 바랍니다.</p>
<ol>
<li>가장 바깥쪽 <code>if</code> 절을 살펴보면 <code>isUndef(vnode.text)</code>로 <code>vnode.text</code>가 정의되어 있지 않을 때 <code>if</code> 절이 동작합니다.</li>
<li>가장 바깥쪽의 <code>else if</code> 절을 살펴보면 <code>oldVnode.text !== vnode.text</code> 일 때, <code>nodeOps.setTextContent(elm, vnode.text)</code>를 실행합니다. 즉 leaf 노드이면서 <code>text</code>가 다를 때 <code>text</code>를 업데이트 합니다.</li>
<li>이전 노드와 새로운 노드 둘다 자식노드들을 가지고 있으면서, 두 노드가 다를 때, <code>updateChildren</code> 함수를 호출합니다.</li>
<li>새로운 노드가 자식을 가지고, 이전 노드가 <code>text</code>를 가질 때, <code>addVnodes</code> 함수를 호출하여 새로운 노드의 자식 노드를 추가합니다.</li>
<li>이전 노드가 자식을 가지고 새로운 노드가 leaf 노드일 때, <code>removeVnodes</code> 함술르 호출하여 이전 노드의 자식 노드를 제거합니다.</li>
<li>이전 노드와 새로운 노드 모두 자식 노드가 없고 이전 노드의 <code>text</code>가 정의 되어 있지 않을 때 <code>nodeOps.setTextContent(elm, '')</code>를 호출하여 <code>text</code>를 제거합니다.</li>
</ol>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">          canMove </span><span style="color:#A0111F;--shiki-dark:#FF9492">&#x26;&#x26;</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> nodeOps.</span><span style="color:#622CBC;--shiki-dark:#DBB7FF">insertBefore</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(parentElm, vnodeToMove.elm, oldStartVnode.elm)</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">        } </span><span style="color:#A0111F;--shiki-dark:#FF9492">else</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span class="line"><span style="color:#66707B;--shiki-dark:#BDC4CC">          // same key but different element. treat as new element</span></span>
<span class="line"><span style="color:#622CBC;--shiki-dark:#DBB7FF">          createElm</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">(newStartVnode, insertedVnodeQueue, parentElm, oldStartVnode.elm, </span><span style="color:#023B95;--shiki-dark:#91CBFF">false</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">, newCh, newStartIdx)</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">        }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">      }</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">      newStartVnode </span><span style="color:#A0111F;--shiki-dark:#FF9492">=</span><span style="color:#0E1116;--shiki-dark:#F0F3F6"> newCh[</span><span style="color:#A0111F;--shiki-dark:#FF9492">++</span><span style="color:#0E1116;--shiki-dark:#F0F3F6">newStartIdx]</span></span>
<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">    }</span></span>

<span class="line"><span style="color:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre>
<p>위의 코드를 그림으로 설명해보도록 하겠습니다.</p>
<p><img src="/assets/img/posts/vuejs/update_children_1.png" alt="vue updateChildren" loading="lazy" decoding="async" width="1556" height="618" srcset="/assets/img/posts/vuejs/nextImageExportOptimizer/update_children_1-opt-640.WEBP 640w, /assets/img/posts/vuejs/nextImageExportOptimizer/update_children_1-opt-1080.WEBP 1080w, /assets/img/posts/vuejs/nextImageExportOptimizer/update_children_1-opt-1920.WEBP 1920w" sizes="(max-width: 640px) 100vw, 1000px"></p>
<p>위의 그림에서 <code>oldCh</code>, <code>newCh</code>는 <code>updateChildren</code> 함수의 파라미터입니다. 각각 이전의 자식 VNode, 새로운 자식 VNode 배열을 나타냅니다. <code>oldStartIdx</code>, <code>oldEndIdx</code>, <code>oldStartVNode</code>, <code>oldEndVNode</code>, <code>newStartIdx</code>, <code>newEndIdx</code>, <code>newStartVNode</code>, <code>newEndVNode</code> 변수를 적용한 그림입니다.</p>
<p>위의 그림의 따라 동작하는 코드를 살펴보겠습니다.</p>
<ul>
<li><code>while (oldStartIdx &#x3C;= oldEndIdx &#x26;&#x26; newStartIdx &#x3C;= newEndIdx) {</code>의 값이 <code>true</code>로 배열을 반복하여 탐색하게 됩니다.</li>
<li><code>if (isUndef(oldStartVnode))</code>와 <code>else if (isUndef(oldEndVnode))</code>로 <code>oldStartVnode</code>와 <code>oldEndVnode</code>가 항상 정의 됩니다.</li>
<li><code>else if (sameVnode(oldStartVnode, newStartVnode))</code>, <code>oldStartVnode</code>와 <code>newStartVnode</code>가 서로 같은 노드라면 이전에 살펴봤던 <code>patchVnode</code> 함수를 실행하여 DOM을 업데이트 합니다.</li>
</ul>
<p><code>oldStartVnode</code>와 <code>newStartVnode</code>가 서로 같은 노드라고 가정한다면,</p>
<p><img src="/assets/img/posts/vuejs/update_children_2.png" alt="vue updateChildren" loading="lazy" decoding="async" width="1556" height="618" srcset="/assets/img/posts/vuejs/nextImageExportOptimizer/update_children_2-opt-640.WEBP 640w, /assets/img/posts/vuejs/nextImageExportOptimizer/update_children_2-opt-1080.WEBP 1080w, /assets/img/posts/vuejs/nextImageExportOptimizer/update_children_2-opt-1920.WEBP 1920w" sizes="(max-width: 640px) 100vw, 1000px"></p>
<p>위의 그림과 같이 변수들이 업데이트 됩니다. 위의 방법을 <code>while</code>문 조건이 <code>true</code>일 때 반복하여 동작합니다.</p>
